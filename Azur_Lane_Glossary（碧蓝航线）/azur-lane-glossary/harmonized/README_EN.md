# Azur Lane harmonised names and five-language ship table (`harmonized`)

## [简体中文](README.md) [日本語](README_JP.md)

This directory stores the **harmonised-name (CN-server replacement name) mapping** and the
**five-language ship-name master table** for Azur Lane. "Harmonised names" are the names the Chinese
mainland client shows after replacing some original ship names with plant/animal stand-ins, e.g.
`峰风` → `樱` and `吹雪` → `桐`. The mapping comes from the game file `ShareCfg/name_code.json`
(`name` = original name, `code` = harmonised name) and is cross-checked against the
Moegirlpedia "Azur Lane / name comparison table".

## File format

All CSVs are **UTF-8 (with BOM)**, **CRLF**, with a header row.

| File | Actual header |
| --- | --- |
| `ship-names-multilingual.csv` | `ship_id,zh_CN,en,ja,zh_TW,ko,english_name,ship_type_zh,ship_type_en,nation_zh,nation_en,variant` |
| `ship-names-harmonized.csv` | `source,target,tgt_lng` |
| `harmonized-names-detailed.csv` | `source,target,tgt_lng,src_lng,name_code_id,kind,ship_type,ship_id,en,ja,zh_TW,wiki_note` |
| `equipment-harmonized.csv` | `source,target,tgt_lng` |
| `ijn-codename-aliases.csv` | `source,target,tgt_lng,src_lng,name_code_id` |

### Reading the three-column tables

In the `source,target,tgt_lng` family (`ship-names-harmonized.csv`, `equipment-harmonized.csv`)
`tgt_lng` is always `zh-CN`, `source` is the client's original name and `target` is the harmonised name:

| `source` | `target` | `tgt_lng` |
| --- | --- | --- |
| 峰风 | 樱 | zh-CN |
| 吹雪 | 桐 | zh-CN |
| Fubuki | 桐 | zh-CN |

### `kind` distribution in `harmonized-names-detailed.csv`

| `kind` | Rows | Meaning |
| --- | ---: | --- |
| `ship` | 1,251 | Ships |
| `equipment` | 8 | Equipment |

`src_lng` distribution: `zh-CN` 436, `en` 255, `ko` 253, `ja` 172, `zh-TW` 143.
One harmonised name maps to several original names, so 1,259 rows correspond to only 1,195 distinct
`source` values and 424 distinct `target` values.

### `ijn-codename-aliases.csv`

`src_lng` distribution: `zh-CN` 434, `en` 383, `ja` 265. `name_code_id` points at the entry ID in
`ShareCfg/name_code.json`, linking a single-character codename (such as 「貃」) to the official ship
name (such as 「阿武隈」).

## Notes

- Harmonised names are the text the **Chinese mainland client actually displays**, not a translator
  rewrite, so they can be used directly as the official Simplified Chinese name.
- Some ships have variants across ship type / nation / retrofit dimensions (META, μ-equipment,
  Type II, ...); the `variant` column marks these.
- Traditional Chinese is spelled `zh_TW` (underscore) here, unlike the `zh-TW` (hyphen) used in the
  three-column tables — do not confuse the two when converting.
- Generated by `tools/build_harmonized.py`, which depends on upstream outputs such as
  `ship-names-multilingual.csv`.
