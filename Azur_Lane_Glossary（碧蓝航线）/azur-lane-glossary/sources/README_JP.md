# 『アズールレーン』用語データの出典（`sources`）

## [简体中文](README.md) [English](README_EN.md)

本ディレクトリは、『アズールレーン』（Azur Lane）用語集の生成過程で使用した**外部出典の取得結果**
を保存します。現在はファイルが 1 つだけで、中国本土版クライアントの艦船調和名マッピングを
検証するために使います。

## 構成

```text
sources/
├── README.md                本説明（簡体字中国語）
├── README_EN.md             英語説明
├── README_JP.md             日本語説明
└── moegirl_name_table.json  萌娘百科「碧蓝航线/名称对照表」の取得結果
```

## ファイル一覧

| ファイル | 種別 | サイズ | 用途 |
| --- | --- | ---: | --- |
| `moegirl_name_table.json` | JSON 配列 | 8,449 バイト | 原名 → 調和名 の手整理対照表。`ShareCfg/name_code.json` の検証に使用 |

### `moegirl_name_table.json` の構造

ファイルは JSON 配列で、各要素が三つ組 `[ID, 原名, 和谐名]` であり、CSV テーブルを行ごとに
書き出した形になっています。

```json
[["ID", "原名", "和谐名"], ["1", "峰风", "樱"], ["2", "吹雪", "桐"], ["3", "白雪", "杉"]]
```

| 位置 | フィールド | 意味 |
| --- | --- | --- |
| `[0]` | `ID` | 萌娘百科の対照表における番号（文字列。ゲーム内の `ship_id` ではない） |
| `[1]` | `原名` | その艦船の原名 |
| `[2]` | `和谐名` | 中国本土版クライアントで差し替えられた名称 |

## 内容の規模

| 項目 | 数量 |
| --- | ---: |
| 配列要素の総数 | 365 |
| ヘッダー行（`["ID", "原名", "和谐名"]`） | 3（インデックス 0、232、348） |
| データ行 | 362 |
| 重複除去後の ID | 360 |

3 つのヘッダー行がデータを 3 つの区間に分けています。インデックス 0 からが艦船の主テーブル、
インデックス 232 からが 400–500 番台（ドイツ／その他の陣営）、インデックス 348 からが
194–230 番台の補足項目です。ID `225` と `226` は区間間の重複によりそれぞれ 2 回出現します。
取得結果はそのまま保存し、重複除去は行いません。

## 注意事項

- 本ディレクトリは**参考出典のスナップショット**にすぎず、用語集の出力には直接関与しません。
  調和名の正式な対応はゲームファイル `ShareCfg/name_code.json` を基準とし、本表はその
  クロスチェックに使用します。
- `ID` は萌娘百科ページの番号であり、リポジトリ内の他のファイルが使う `ship_id` /
  `name_code_id` とは**別の番号体系**です。ファイルをまたいで関連付けないでください。
- 上流ページはゲームのバージョンに合わせて更新されます。本スナップショットは今回の整理時点の
  状態に対応します。
