# 《碧蓝航线》术语数据来源（`sources`）

## [English](README_EN.md) [日本語](README_JP.md)

本目录保存《碧蓝航线》（Azur Lane）术语库生成过程中使用的**外部来源抓取结果**。
目前只有一份文件，用于校验国服客户端的舰船和谐名映射。

## 目录结构

```text
sources/
├── README.md                本说明（简体中文）
├── README_EN.md             英文说明
├── README_JP.md             日文说明
└── moegirl_name_table.json  萌娘百科《碧蓝航线/名称对照表》抓取结果
```

## 文件说明

| 文件 | 类型 | 大小 | 用途 |
| --- | --- | ---: | --- |
| `moegirl_name_table.json` | JSON 数组 | 8,449 字节 | 原名 → 和谐名 的人工整理对照表，用于交叉校验 `ShareCfg/name_code.json` |

### `moegirl_name_table.json` 结构

文件是一个 JSON 数组，每个元素是一个三元组 `[ID, 原名, 和谐名]`，相当于把 CSV 表按行写入：

```json
[["ID", "原名", "和谐名"], ["1", "峰风", "樱"], ["2", "吹雪", "桐"], ["3", "白雪", "杉"]]
```

| 位置 | 字段 | 含义 |
| --- | --- | --- |
| `[0]` | `ID` | 萌娘百科对照表中的编号（字符串，并非游戏内 `ship_id`） |
| `[1]` | `原名` | 该舰船的原始名称 |
| `[2]` | `和谐名` | 国服客户端替换后的名称 |

## 内容规模

| 项目 | 数量 |
| --- | ---: |
| 数组元素总数 | 365 |
| 表头行（`["ID", "原名", "和谐名"]`） | 3（分别位于索引 0、232、348） |
| 数据行 | 362 |
| 去重后的 ID | 360 |

3 个表头行把数据分成三段：索引 0 起为舰船主表，索引 232 起为 400–500 段（德国 / 其他阵营），
索引 348 起为 194–230 段的补充条目。ID `225`、`226` 各出现两次，来自分段之间的重复。
抓取结果按原样保存，不做去重。

## 说明

- 本目录只是**参考来源的快照**，不直接参与术语库输出；和谐名的正式映射以游戏文件
  `ShareCfg/name_code.json` 为准，本表用于交叉校验。
- `ID` 是萌娘百科页面的编号，与仓库中其它文件的 `ship_id` / `name_code_id` **不是同一套编号**，
  不要跨文件关联。
- 上游页面会随游戏版本更新，本快照对应的是本次整理时的状态。
