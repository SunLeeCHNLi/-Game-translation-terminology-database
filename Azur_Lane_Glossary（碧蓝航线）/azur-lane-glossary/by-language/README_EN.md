# Azur Lane source-language termbases (`by-language`)

## [简体中文](README.md) [日本語](README_JP.md)

This directory is the **source-language view** of the Azur Lane ship termbase: the same ship-name
table is split into several sub-tables by `src_lng` (the source language), and the `target` of every
file is always the **Simplified Chinese (`zh-CN`)** name. It is the grouped-by-source-language
equivalent of `zh-CN/glossary.csv`, intended to **narrow the matching scope** inside CAT tools —
letting only one source language participate in matching.

## Layout

```text
by-language/
├── README.md                  this document (Simplified Chinese)
├── README_EN.md               English document
├── README_JP.md               Japanese document
├── glossary_en-zh-CN.csv      source = English original names
├── glossary_ja-zh-CN.csv      source = Japanese original names
├── glossary_ko-zh-CN.csv      source = Korean original names
└── glossary_zh-TW-zh-CN.csv   source = Traditional Chinese original names
```

## File format

All files are **UTF-8 (with BOM)**, **CRLF**, with a header row, and the column layout matches the
main table exactly:

```csv
source,target,tgt_lng
Abercrombie,阿贝克隆比,zh-CN
Abukuma,阿武隈,zh-CN
Acasta,阿卡司塔,zh-CN
```

| Column | Meaning |
| --- | --- |
| `source` | The ship name in that source language (English / Japanese / Korean / Traditional Chinese) |
| `target` | The corresponding Simplified Chinese name |
| `tgt_lng` | Always `zh-CN` |

## File details

| File | Source language | Data rows | Distinct `source` | Distinct `target` |
| --- | --- | ---: | ---: | ---: |
| `glossary_en-zh-CN.csv` | English | 1,544 | 1,544 | 856 |
| `glossary_ja-zh-CN.csv` | Japanese | 696 | 696 | 695 |
| `glossary_ko-zh-CN.csv` | Korean | 814 | 814 | 811 |
| `glossary_zh-TW-zh-CN.csv` | Traditional Chinese | 538 | 538 | 538 |

**3,592** aligned rows in total. The English table has only 856 distinct `target` values because
one-ship-many-names cases concentrate on the English side (several English spellings sharing one
Chinese name); the other three tables are essentially one-to-one.

## Notes

- This directory covers **ship names only**, not nautical / military / game terminology; see
  `../zh-CN/terms.csv` for terms.
- The four sub-tables are **different slices of the same ship set** and share `target` values with
  each other — do not blindly merge and de-duplicate them.
- To import every source language at once, use `../zh-CN/glossary.csv` instead of this directory.
- Generated by `tools/build_glossary.py` (the `SPLIT` output constant); this directory is a
  published snapshot of its output.
