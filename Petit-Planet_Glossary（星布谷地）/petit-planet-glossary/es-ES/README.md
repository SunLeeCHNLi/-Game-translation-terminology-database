# 《星布谷地》术语库 — Español（`es-ES`）

[← 返回游戏总说明](../README.md)

本目录是**以 `es-ES` 为目标语言**的术语库：每一条都是「其他语言词条 → Español」的对照。
`tgt_lng` 列固定为 `es-ES`；`source` 列收录官方本地化文本中其余语言的写法。
译文全部来自官方已实装的本地化文本（官方网站多语言本地化文件、官方 HoYoLAB 公告），
按同一文本键或同一官方名称对齐，**不含二次机翻**。

## 文件

- `NN_xxx/NN_xxx_glossary.csv` —— `source,target,tgt_lng` 三列，可直接导入沉浸式翻译等 CAT / 术语管理工具；
- `NN_xxx/NN_xxx_terms.csv` —— 本语言词条清单（`id,term,src_table`），便于校对与回查；
- `00_master/index.csv` —— 本语言的分类索引与条数
  （`category,label,term_count,glossary_count,glossary_file,terms_file,target_language`）；
- `00_master/README.md` —— 本语言数据目录的说明。
- 上游十五语并排总表：`../multilingual/all_languages_master.csv`。

## 说明

- **译文来源与对齐方式**：官方以**同一本地化 Key** 提供 15 种语言文本（官方站点本地化文件共 443 个 Key），
  因此各语言之间可直接一一对齐，属于官方本地化，而非二次翻译；
  官方 HoYoLAB 公告（`gids=10`）用于补充测试名称、邻居名与系统名词。
- **语言标签说明**：`tgt_lng` 固定为 `es-ES`；`source` 可能是任一其他语言的官方写法，同一词条的不同语言写法各占一行。
- **编码说明**：所有 CSV 均为 **UTF-8 with BOM + CRLF**，Excel 双击即可正确显示。
- **已知限制**：
  - 游戏客户端的多语言字符串尚未公开，本库官方译文来自**官方网站本地化文件与官方公告**；
    官方网站文案可能属于 **Web Only** 层级，游戏内文本以客户端为准；
  - 道具、家具、鱼类、昆虫、食谱、商店等条目目前仅有社区数据库（petitplanet.life）的**英文名称**，
    缺少官方多语言对照，因此以 `source = target`（均为英文）记录并标注 `community_database`，未编造任何译名；
  - 官方网站本地化文件中图片链接与空值已过滤；少数 Key 在部分语言无文本，未强行补全；
  - 《星布谷地》仍在测试阶段，不同测试阶段（居心地测试 / 星旅测试 / 连接测试）的译名可能变化，
    本库以当前版本（Final Beta Test，连接测试）为准。
- **更新与复现**：本库是纯数据产品，游戏目录下**没有 `tools/` 目录、也没有任何脚本**。
