# 星布谷地（Petit Planet）十五语并排总表（`multilingual/`）

## [English](README_EN.md) [日本語](README_JP.md)

本目录把《星布谷地》术语库的全部 **3606** 条词条按「一条一行」摊开，十五种语言并排展示，便于横向比对与二次加工。以单一语言为目标语言的拆分结果在上一层目录的 `../zh-CN/`、`../en-US/` 等语言文件夹中。

## 目录结构

```text
multilingual/
└── all_languages_master.csv   十五语并排总表（3606 行数据）
```

## 文件格式

`all_languages_master.csv` 为 **UTF-8（含 BOM）** 编码、**CRLF** 换行、首行为表头。

| 列 | 说明 |
| --- | --- |
| `category` | 分类编号，例如 `00_game_title` |
| `term` | 词条标识；仅英文名称的条目以英文写法作为标识 |
| `zh-CN` | 简体中文 |
| `zh-TW` | 繁体中文 |
| `en-US` | 英文 |
| `ja-JP` | 日文 |
| `ko-KR` | 韩文 |
| `fr-FR` | 法文 |
| `de-DE` | 德文 |
| `es-ES` | 西班牙文 |
| `ru-RU` | 俄文 |
| `pt-PT` | 葡萄牙文 |
| `it-IT` | 意大利文 |
| `tr-TR` | 土耳其文 |
| `th-TH` | 泰文 |
| `vi-VN` | 越南文 |
| `id-ID` | 印尼文 |

## 说明

- 每条词条一行，十五种语言并排；空单元格表示该词条在该语言下缺失。
- `en-US` 的非空条目数明显高于其他语言，因为道具、家具、鱼类、昆虫、食谱、商店等分类目前只有英文名称，缺少官方多语言对照。
- 若只想取某一目标语言的术语库，请直接使用上一层目录 `../<lang>/` 下的分类 CSV，无需从本目录拆分。
- 游戏级总说明见 `../README.md` / `../README_EN.md` / `../README_JP.md`。
