# 『プチプラネット』用語集 / Petit Planet Terminology Database

## [中文](README.md) [English](README_EN.md)

本フォルダは、HoYoverse の生活シミュレーションゲーム『プチプラネット』（Petit Planet / 星布谷地）の
非公式な用語対照データベースです。**15 の対象言語**を収録しています
（簡体字中国語・繁体字中国語・英語・日本語・韓国語・フランス語・ドイツ語・スペイン語・ロシア語・
ポルトガル語・イタリア語・トルコ語・タイ語・ベトナム語・インドネシア語）。

| 名称 | 表記 |
| --- | --- |
| 簡体字中国語 | 星布谷地 |
| 繁体字中国語 | 星布谷地 |
| 英語 | Petit Planet |
| 日本語 | プチプラネット |
| 韓国語 | 쁘띠플래닛 |
| フランス語 | P'tite Planète |

訳文はすべて、**公式の多言語ローカライズテキスト**（公式サイトのローカライズファイルは
**15 言語すべてが同一のローカライズキー**を使用）と、**公式 HoYoLAB のお知らせ**（`gids=10`、
こちらも 15 言語）から取得しています。同一テキストキーまたは同一の公式名称で対応付けており、
二次翻訳ではなく**公式ローカライズ**です。機械翻訳は使用していません。

## 使い方

1. **単一ファイル** — 対象言語のフォルダ（例：`zh-CN/`）を開き、`neighbor.csv`
   のようなカテゴリ別ファイルをダウンロードします。変換なしで Immersive Translate などの用語ツールに
   そのまま読み込めます。
2. **言語フォルダごと** — その言語フォルダ内の全カテゴリファイルをダウンロードします。
3. **15 言語の並列表** — `petit-planet-glossary/multilingual/all_languages_master.csv`（1 言語につき 1 列）。

## ディレクトリ構成

```text
Petit-Planet_Glossary（星布谷地）/
  README.md                中国語
  README_EN.md             英語
  README_JP.md             日本語
  petit-planet-glossary/   用語データ（対象言語ごとに 15 セット）
    README.md              サブライブラリの説明（カテゴリ・クリーンアップ規則）
    zh-CN/                 簡体字中国語向け（フラットなカテゴリ別 CSV）
    zh-TW/  en-US/  ja-JP/  ko-KR/  fr-FR/  de-DE/  es-ES/
    ru-RU/  pt-PT/  it-IT/  tr-TR/  th-TH/  vi-VN/  id-ID/
    _master/               言語別 index.csv と説明（<lang>__index.csv）
    multilingual/          15 言語の並列表
```

## ファイル形式

`<类目>.csv` は厳密に 3 列です。

```text
source,target,tgt_lng
Petit Planet,星布谷地,zh-CN
プチプラネット,星布谷地,zh-CN
Petit Planet,星布谷地,zh-TW
Starsea,星海,zh-CN
```

- `source` — 元のローカライズ文字列（内部 ID ではありません）
- `target` — 対象言語の正式名称
- `tgt_lng` — 対象言語コード

`*__terms.csv` はその言語の見出し一覧（`id,term,src_table`）で、校正と照合に使用します。

## 既知の制限

- **ゲームクライアントの多言語文字列は公開されていません。** 本データベースの公式訳は公式サイトの
  ローカライズファイルと公式お知らせに基づきます。公式サイトの文言は **Web Only** の可能性があり、
  ゲーム内テキストはクライアントで確認してください。
- アイテム・家具・魚・虫・レシピ・ショップなどの項目は、現在 petitplanet.life のコミュニティ
  データベースにある**英語名のみ**です。公式の多言語対照が存在しないため、
  `source = target`（いずれも英語）として `community_database` と明示しています。
  **訳名を創作することはしていません。**
- 公式ローカライズファイル内の画像リンクと空値は除外しています。
- 本フォルダは**純粋なデータ製品**であり、`tools/` ディレクトリも実行可能なスクリプトもありません。

## 品質チェック

- **第 1 回（構造）** — 空の source / target、誤った言語コード、重複行、HTML タグ、JSON の残骸、
  内部 ID、エスケープの残骸：すべて問題なし。
- **第 2 回（言語方向）** — 各 target 列の文字体系が `tgt_lng` と一致するか検証：すべて問題なし。
- **第 3 回（相互照合）** — ゲーム名、ご近所さんの名前、UI 文言、世界観用語、テスト名を、
  公式ローカライズファイルおよび公式お知らせと項目ごとに照合：すべて問題なし。
