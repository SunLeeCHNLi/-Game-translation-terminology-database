# Honkai: Star Rail termbase statistics and validation (`Metadata`)

## [简体中文](README.md) [日本語](README_JP.md)

This directory holds the **statistics report** for the Honkai: Star Rail (HSR) termbase. It is an
aggregate view of the per-language tables under `hsr-glossary/`; it does not store terminology data
itself, only used to inspect size, distribution and validation results.

## Layout

```text
Metadata/
├── README.md          this document (Simplified Chinese)
├── README_EN.md       English document
├── README_JP.md       Japanese document
└── statistics.md      termbase statistics report
```

## File details

| File | Type | Purpose |
| --- | --- | --- |
| `statistics.md` | Markdown | Termbase statistics: totals, per-language, per-category, historical sources, spot checks |

### Sections of `statistics.md`

| Section | Contents |
| --- | --- |
| Totals | Total rows, unique concept keys, target languages, categories, confirmed / unconfirmed entries, machine-translated entries, historical and curated entries, conflict groups |
| Per-language counts | Row count for each of the 13 target languages (`zh-CN` … `vi-VN`) |
| Per-category counts | Unique concept keys and all-language rows for each of the 26 categories (`01_character` … `26_other`) |
| Historical sources | Differences detected against StarRailStaticAPI 2.3.0 and HSR-Mapping-DATA 4.0 |
| Second-round spot check | 104 samples per category, and how many were found in the StarRailRes index |

## Notes

- This directory **does not take part in terminology generation**; it only aggregates results. The
  terminology itself lives under `../hsr-glossary/<lang>/`.
- "Confirmed entries" means the target text can be verified character by character in the client
  TextMap; "unconfirmed entries" and "machine-translated entries" are both 0.
- The spot check cross-validates name-to-ID correspondence between StarRailRes and the client
  TextMap, which are two arrangements of the same data. For categories without a StarRailRes
  counterpart, character-by-character verification against the client TextMap is authoritative.
- The report is generated by `tools/make_hsr_docs.py`; `statistics.md` is written to
  `ROOT / "Metadata"`.
