# 『崩壊：スターレイル』用語集の統計と検証（`Metadata`）

## [简体中文](README.md) [English](README_EN.md)

本ディレクトリは『崩壊：スターレイル』（Honkai: Star Rail / HSR）用語集の**統計レポート**を
保存します。`hsr-glossary/` 配下の言語別テーブルを集計したビューであり、用語データ自体は
置かず、規模・分布・検証結果の確認にのみ使用します。

## 構成

```text
Metadata/
├── README.md          本説明（簡体字中国語）
├── README_EN.md       英語説明
├── README_JP.md       日本語説明
└── statistics.md      用語集の統計レポート
```

## 注意事項

- 本ディレクトリは**用語生成には関与せず**、結果を集計するだけです。用語本体は
  `../hsr-glossary/<lang>/` 配下にあります。
- 「確認済み項目」とは、対象テキストがクライアント TextMap 内で一字ずつ検証できることを指します。
  「未確認項目」と「機械翻訳項目」はいずれも 0 です。
- サンプル確認では、StarRailRes とクライアント TextMap という同源の 2 つの整理方法を突き合わせて、
  名称と ID の対応関係を検証しています。StarRailRes に対応ファイルがない門類については、
  クライアント TextMap による一字ずつの検証を基準とします。
- レポートは `tools/make_hsr_docs.py` が生成し、`statistics.md` の出力先は `ROOT / "Metadata"` です。
