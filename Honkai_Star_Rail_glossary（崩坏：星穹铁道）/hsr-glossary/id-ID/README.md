## Catatan

- Teks terjemahan berasal dari lokalisasi klien (TextMap / ExcelOutput), diselaraskan dengan kunci teks yang sama — bukan terjemahan ulang.
- Jika bahasa target tidak memiliki teks untuk sebuah kunci, baris tidak dibuat dan tidak diisi dengan terjemahan mesin.
- Satu kunci teks bisa punya beberapa padanan resmi tergantung konteks; semuanya dipertahankan.
- Dibuat oleh `../../tools/build_hsr_glossary.py`, dapat direproduksi.
