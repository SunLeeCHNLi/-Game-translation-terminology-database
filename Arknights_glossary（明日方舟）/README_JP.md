# Arknights 用語集 / Arknights Terminology Database / 《明日方舟》翻译术语库

## [中文](README.md) [English](README_EN.md)

『アークナイツ』（Arknights）は、Hypergryph（鷹角網絡）が開発したタワーディフェンス系ストラテジー
モバイルゲームです。

本ディレクトリは、**各地区サーバーの公式クライアントから展開したデータテーブル**
（`cn` / `tw` / `en` / `jp` / `kr` の 5 サーバー）から抽出・整理した多言語用語集です。
**23,840** 件の対応語彙、**266,111** 行の対照データを収録し、**目標言語**ごとに **5** 套の独立した
用語集（簡体字中国語・繁体字中国語・英語・日本語・韓国語）に分割、各套はさらに **20** 分類に
分かれ、1 套あたり **13,000–14,100** 件の重複除去済み訳語を含みます。

> **23,840** は分類レベルの対応語彙数（分類ごとに 5 サーバーを対応付けた一意 ID 数の合計）、
> **266,111** は 5 言語ディレクトリ × 20 分類の CSV データ行数の合計です。両者は単位が異なるため
> 混同しないでください。

訳語はすべてクライアントの公式ローカライズ文本を、同一の項目 ID で 1 件ずつ対応させたもので、
**二次翻訳・機械翻訳ではありません**。

## 使用方法

1. **単一ファイルのダウンロード**：`glossary/<言語コード>/` を開き、必要な `NN_<分類>.csv` を
   そのままダウンロードします。ファイルは `source,target,tgt_lng` の 3 列で、没入型翻訳などの
   用語ツールに直接インポートできます。たとえば「英→中」の対訳表が必要なら
   `glossary/zh-CN/01_干员名称.csv` をダウンロードしてください。
2. **言語ディレクトリごとダウンロード**：`glossary/<言語コード>/` を開いてディレクトリ全体を
   ダウンロードするか、同ディレクトリ内の `_all.json`（その言語の 20 分類を統合した JSON、
   UTF-8・BOM なし）を取得します。
3. **リポジトリ全体をクローンして再生成**：本リポジトリをクローンし、「使用した関連コンテンツ」に
   挙げた上流リポジトリのソースを別途ダウンロードしたうえで、`tools/` 内のスクリプトで再生成します
   （「再生成」を参照）。

```text
Arknights_glossary（明日方舟）/
├── README.md                 # 中国語版の説明（原本）
├── README_EN.md              # 英語版の説明
├── README_JP.md              # 本ファイル（日本語版の説明）
├── glossary/                 # 用語集データ本体
│   ├── README.md             # 用語集の詳細説明（分類表・出典・生成方法）
│   ├── zh-CN/                # 目標言語 = 簡体字中国語
│   │   ├── README.md         # 簡体字中国語の説明
│   │   ├── 01_干员名称.csv
│   │   ├── 02_干员异格.csv
│   │   ├── ...
│   │   ├── 20_游戏机制.csv
│   │   └── _all.json         # 上記 20 分類を統合した JSON
│   ├── zh-TW/                # 目標言語 = 繁体字中国語（構成は zh-CN と同一）
│   ├── en-US/                # 目標言語 = 英語（構成は zh-CN と同一）
│   ├── ja-JP/                # 目標言語 = 日本語（構成は zh-CN と同一）
│   └── ko-KR/                # 目標言語 = 韓国語（構成は zh-CN と同一）
└── tools/                    # 生成スクリプトとメタデータ
    ├── build_glossary.py     # 外部の _data/gamedata を読み、glossary/ を出力
    ├── write_readme.py       # _summary.json から glossary/README.md を生成
    └── _summary.json         # 分類ごとの語彙数・5 言語揃い数・言語別行数
```

各言語ディレクトリ（`glossary/zh-TW/`、`glossary/en-US/`、`glossary/ja-JP/`、`glossary/ko-KR/`）は
`zh-CN/` と完全に同構成です。その言語で書かれた `README.md` 1 件、簡体字中国語の
`README_zh-CN.md` 1 件、20 分類の CSV、そして `_all.json` 1 件が入っています。

### ファイル形式

各 CSV は 3 列で、**UTF-8 with BOM + CRLF** 保存です（Excel でダブルクリックしても文字化けしません）：

| source | target | tgt_lng |
| --- | --- | --- |
| Amiya | 阿米娅 | zh-CN |
| アーミヤ | 阿米娅 | zh-CN |
| 阿米婭 | 阿米娅 | zh-CN |
| 아미야 | 阿米娅 | zh-CN |

- `target`：そのファイルの目標言語における公式訳語；
- `tgt_lng`：目標言語タグ。格納されているディレクトリ名と同じ；
- `source`：同じ語彙の**他 4 言語**での表記。

| 英語（`en`） | `51.4.0` |
| 繁体字中国語（`tw`） | `50.8.0` |
| 日本語（`jp`） | 上流に独立したバージョン番号の記載はなく、展開バッチに追随 |
| 韓国語（`kr`） | 上流に独立したバージョン番号の記載はなく、展開バッチに追随 |

## 再生成

```bash
# 1) 5 つの言語ディレクトリの用語集を生成
#    （<ゲームルート>/_data/gamedata を読み、<ゲームルート>/glossary/ へ出力）
python tools/build_glossary.py

# 2) tools/_summary.json から glossary/README.md を再生成
python tools/write_readme.py
```

**出力先の確認**（スクリプトが正しい場所へ書き込むことの確認）：

```bash
python tools/build_glossary.py    # 出力先は glossary/ であり、tools/glossary/ ではない
python tools/write_readme.py      # glossary/README.md を更新する
```

> `_data/gamedata` は**外部データディレクトリ**（上流 `ArknightsGamedata` リポジトリの 5 地区分の
> 展開結果）であり、**本リポジトリには同梱されていません**。再生成するには「使用した関連コンテンツ」
> の記載に従ってご自身で用意してください。

生成方法（概要。詳細は [`glossary/README.md`](glossary/README.md) を参照）：

1. **ID による対応付け**：すべてのテーブルを項目 ID（`char_002_amiya`、`skchr_amiya_2` など）で
   キーとし、5 地区の同一 ID の値を 1 組にまとめます；
2. **名称系の分類**は公式フィールドをそのまま取得します（オペレーター名、スキル名、ステージ名、
   敵名など）；
3. **説明文系の分類**（`05_技能描述关键术语` と `20_游戏机制` の一部）は
   **プレースホルダー分割 + 全コーパス投票**を採用：`<@ba.vup>`、`{atk:0%}` などのマークは
   全言語で完全に一致するため、マークで分割すれば構造が揃った断片が得られます。さらに同一の
   中国語断片について各言語で最も多く現れる表記を採用し、語順の違いによるズレを解消します；
4. **クリーニング**：リッチテキストタグ、改行、対になる引用符や二重かぎ括弧を除去し、
   数字のみ・記号のみの断片を除外します；
5. 分類内で `(source, target)` により重複を除去し、source と target の表記が同じ行は出力しません。
