# 《明日方舟》Arknights 翻译术语库 / Arknights Terminology Database / アークナイツ 用語集

## [English](README_EN.md) [日本語](README_JP.md)

《明日方舟》（Arknights）是一款由鹰角网络（Hypergryph）开发的塔防策略手游。

本目录是从各地区服**官方客户端解包数据表**（`cn` / `tw` / `en` / `jp` / `kr` 五个区服）中抽取并整理的多语言术语库，
共 **23,840** 条对齐词条、**266,111** 行对照，按**目标语言**拆分为 **5** 套独立术语库
（简体中文、繁体中文、英文、日文、韩文），每套内部再按 **20** 个分类归档，
单套术语库含 **13,000–14,100** 条去重译名。

> **23,840** 是分类级的对齐词条数（每个分类下跨五区对齐的唯一 ID 数之和），
> **266,111** 是 5 个语言目录 × 20 个分类的 CSV 数据行数合计；两者口径不同，不要混用。

译文全部取自客户端官方本地化文本，按同一条目 ID 逐条对齐，**非二次翻译、非机翻**。

## 使用方法

1. **单文件下载**：进入 `glossary/<语言代码>/` 目录，直接下载需要的 `NN_<分类>.csv`。
   文件为 `source,target,tgt_lng` 三列，可直接导入沉浸式翻译等术语工具。
   例如要「英→中」词表，下载 `glossary/zh-CN/01_干员名称.csv` 即可。
2. **整个语言目录打包下载**：进入 `glossary/<语言代码>/` 后下载整个目录，
   或直接取该目录下的 `_all.json`（该语言 20 个分类的合并版，UTF-8 无 BOM 的 JSON）。
3. **克隆整个仓库自行复现**：克隆本仓库，并另行下载「使用的相关内容」中引用的上游仓库源码，
   按 `tools/` 下的脚本重新生成（见「生成与复现」）。

### 文件格式

每个 CSV 为三列，**UTF-8 with BOM + CRLF**（Excel 双击可直接打开中文不乱码）：

| source | target | tgt_lng |
| --- | --- | --- |
| Amiya | 阿米娅 | zh-CN |
| アーミヤ | 阿米娅 | zh-CN |
| 阿米婭 | 阿米娅 | zh-CN |
| 아미야 | 阿米娅 | zh-CN |

- `target`：该文件所属目标语言的官方译名；
- `tgt_lng`：目标语言标签，等于所在目录名；
- `source`：同一词条在**其他 4 种语言**中的写法。

## 生成与复现

```bash
# 1) 生成 5 个语言目录的术语库（读取 <游戏根>/_data/gamedata，输出 <游戏根>/glossary/）
python tools/build_glossary.py

# 2) 依据 tools/_summary.json 重新生成 glossary/README.md
python tools/write_readme.py
```

**目录检查**（确认生成脚本落在正确位置）：

```bash
python tools/build_glossary.py    # 应输出到 glossary/，而不是 tools/glossary/
python tools/write_readme.py      # 应更新 glossary/README.md
```

> `_data/gamedata` 是**外部数据目录**（上游 `ArknightsGamedata` 仓库的五区解包结果），
> **未随本仓库分发**，需先按「使用的相关内容」一节自行下载准备后才能复现。

生成方法（简述，完整说明见 [`glossary/README.md`](glossary/README.md)）：

1. **按 ID 对齐**：所有表格以条目 ID（如 `char_002_amiya`、`skchr_amiya_2`）为键，把 5 个区服的同一 ID 值配成一组；
2. **名称类分类**直接取官方字段（干员名、技能名、关卡名、敌人名等）；
3. **描述类分类**（`05_技能描述关键术语`、部分 `20_游戏机制`）采用**占位符分段 + 全语料投票**：
   文本中的 `<@ba.vup>`、`{atk:0%}` 等标记在各语言完全一致，以标记切分即可得到结构对齐的片段，
   再对同一中文片段统计各语言出现最多的写法，消除语序差异带来的错配；
4. **清洗**：去除富文本标签、换行、成对引号与书名号，过滤纯数字 / 纯符号片段；
5. 同一分类内按 `(source, target)` 去重，源语言与目标语言写法完全相同的行不写入。
