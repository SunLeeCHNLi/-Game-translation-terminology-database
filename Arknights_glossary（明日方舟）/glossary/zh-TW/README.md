# 《明日方舟》術語庫 — 繁體中文（`zh-TW`）

[← 返回遊戲總說明](../README.md)

本目錄是**以 `zh-TW`（繁體中文）為目標語言**的術語庫：每一條都是「其他語言詞條 → 繁體中文」的對照。
共 **14,080** 條詞條（20 個分類詞條數之和，跨分類去重後為 13,040 條）、**53,145** 行對照；
`tgt_lng` 欄固定為 `zh-TW`，`source` 欄收錄同一詞條在其余 4 種語言（`zh-CN` / `en-US` / `ja-JP` / `ko-KR`）中的寫法。

## 檔案

- `NN_<分類>.csv` — 共 20 個，即 `01_干员名称.csv` … `20_游戏机制.csv`。
  `source,target,tgt_lng` 三欄，可直接匯入沉浸式翻譯等 CAT / 術語管理工具。
- `_all.json` — 上述 20 個 CSV 的合併版（UTF-8，無 BOM 的 JSON），
  結構為 `{"tgt_lng": "zh-TW", "categories": {"<分類>": [{"source","target","tgt_lng"}, …]}}`，
  共收錄 53,145 條對照，內容與 20 個 CSV 完全一致。
- 本說明檔案 `README.md`，以及簡體中文版 `README_zh-CN.md`。

> 分類檔案名在所有語言目錄中保持中文（如 `01_干员名称.csv`），便於跨語言對照與指令碼統一處理。

## 說明

- **譯文來源與對齊方式**：全部來自各地區伺服器官方客戶端解包資料表（上游 `ArknightsGamedata` 倉庫的
  `tw` 區，即繁中／國際服），所有表格以條目 ID（如 `char_002_amiya`、`skchr_amiya_2`）為鍵跨 5 個
  伺服器對齊，因此是**官方本地化文本的逐條對照，非二次翻譯**。
- **語言標籤**：`zh-TW` = 繁體中文（繁中服）。本目錄 `target` 欄固定為繁體中文官方譯名；
  `source` 欄可能來自 `zh-CN`（簡中）、`en-US`（英文）、`ja-JP`（日文）、`ko-KR`（韓文）任意一種。
  簡中與繁中是兩套各自獨立的官方本地化，譯名並非總是只差繁簡轉換。
- **編碼**：UTF-8 with BOM + CRLF，Excel 雙擊可直接開啟且中文不亂碼；
  `_all.json` 為 UTF-8（無 BOM）。
- **已知限制**：
  - `05_技能描述关键术语` 與 `20_游戏机制` 由文本自動挖掘（佔位符分段 + 全語料投票），
    少數條目仍是短語片段而非嚴格術語，建議按需人工複核；
  - 關卡、活動等大量同名詞條會各自成行，未做跨條目合併；
  - 幹員異格僅收錄異格形態本身，基礎幹員見 `01_干员名称`；
  - 繁中服進度落後於簡中服，較新的內容尚未實裝，因此本目錄部分分類的行數少於 `zh-CN`
    （生成時要求同一 ID 至少有兩種語言存在）。
