# 《明日方舟》术语库 — 繁体中文（`zh-TW`）

[← 返回游戏总说明](../README.md)

本目录是**以 `zh-TW`（繁体中文）为目标语言**的术语库：每一条都是「其他语言词条 → 繁体中文」的对照。
共 **14,080** 条词条（20 个分类词条数之和，跨分类去重后为 13,040 条）、**53,145** 行对照；
`tgt_lng` 列固定为 `zh-TW`，`source` 列收录同一词条在其余 4 种语言（`zh-CN` / `en-US` / `ja-JP` / `ko-KR`）中的写法。

## 文件

- `NN_<分类>.csv` — 共 20 个，即 `01_干员名称.csv` … `20_游戏机制.csv`。
  `source,target,tgt_lng` 三列，可直接导入沉浸式翻译等 CAT / 术语管理工具。
- `_all.json` — 上述 20 个 CSV 的合并版（UTF-8，无 BOM 的 JSON），
  结构为 `{"tgt_lng": "zh-TW", "categories": {"<分类>": [{"source","target","tgt_lng"}, …]}}`，
  共收录 53,145 条对照，内容与 20 个 CSV 完全一致。
- 本说明文件 `README_zh-CN.md`，以及繁体中文版 `README.md`。

> 分类文件名在所有语言目录中保持中文（如 `01_干员名称.csv`），便于跨语言对照与脚本统一处理。

## 说明

- **译文来源与对齐方式**：全部来自各区服官方客户端解包数据表（上游 `ArknightsGamedata` 仓库的
  `tw` 区，即繁中服），所有表格以条目 ID（如 `char_002_amiya`、`skchr_amiya_2`）为键跨 5 个区服对齐，
  因此是**官方本地化文本的逐条对照，非二次翻译**。
- **语言标签**：`zh-TW` = 繁体中文（繁中服）。本目录 `target` 列固定为繁体中文官方译名；
  `source` 列可能来自 `zh-CN`（简中）、`en-US`（英文）、`ja-JP`（日文）、`ko-KR`（韩文）任意一种。
  简中与繁中是两套各自独立的官方本地化，译名并非总是只差繁简转换。
- **编码**：UTF-8 with BOM + CRLF，Excel 双击可直接打开且中文不乱码；`_all.json` 为 UTF-8（无 BOM）。
- **已知限制**：
  - `05_技能描述关键术语` 与 `20_游戏机制` 由文本自动挖掘，少数条目仍是短语片段而非严格术语；
  - 关卡、活动等大量同名词条会各自成行，未做跨条目合并；
  - 干员异格仅收录异格形态本身，基础干员见 `01_干员名称`；
  - 繁中服进度落后于简中服，因此本目录部分分类的行数少于 `zh-CN`。
