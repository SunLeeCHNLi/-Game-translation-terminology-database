# アークナイツ 用語集 — 日本語（`ja-JP`）

[← ゲーム全体の説明に戻る](../README.md)

本ディレクトリは**目標言語を `ja-JP`（日本語）とする**用語集です。各行は「他言語の語彙 → 日本語」の
対照になっています。**13,920** 件の語彙（20 分類の語彙数の合計。分類をまたいで重複を除くと 12,893 件）、
**53,262** 行の対照を収録しています。`tgt_lng` 列は常に `ja-JP` で、`source` 列には同じ語彙の
他 4 言語（`zh-CN` / `zh-TW` / `en-US` / `ko-KR`）での表記が入ります。

## ファイル

- `NN_<分類>.csv` — 全 20 ファイル（`01_干员名称.csv` … `20_游戏机制.csv`）。
  `source,target,tgt_lng` の 3 列で、没入型翻訳などの CAT・用語管理ツールに直接インポートできます。
- `_all.json` — 上記 20 個の CSV を統合した UTF-8（BOM なし）の JSON。
  構造は `{"tgt_lng": "ja-JP", "categories": {"<分類>": [{"source","target","tgt_lng"}, …]}}` で、
  20 個の CSV と同じ 53,262 件の対照を収録しています。
- 本ファイル `README.md` と、簡体字中国語版の `README_zh-CN.md`。

> 分類のファイル名は全言語ディレクトリで中国語のまま統一しています（例：`01_干员名称.csv` ＝
> オペレーター名）。言語をまたいで分類を対応させやすくし、スクリプトで統一的に扱うためです。

- **語彙数**：その分類の CSV における `target` 列の**重複を除いた件数**（同じ日本語訳語は 1 件と数えます）。
- **対照行数**：CSV の**データ行数**（ヘッダーを除く）。1 件の語彙が「他 4 言語の source」によって

  行数は「語彙数 × 4」より少し少なくなります。
- 「合計」は 20 分類の単純合計です。同じ日本語訳語が複数の分類に現れることがあり（レベル違いの
  同名ステージ、同名の敵など）、20 分類をまとめて重複を除くと **12,893** 件の一意な訳語になります。

## 説明

- **訳語の出典と対応付け**：すべて各地区サーバー公式クライアントの展開済みデータテーブル
  （上流 `ArknightsGamedata` リポジトリの `jp` 区 ＝ 日本サーバー）由来です。すべてのテーブルを
  項目 ID（`char_002_amiya`、`skchr_amiya_2` など）でキーとして 5 サーバー分を対応付けているため、
  **公式ローカライズ文本の 1 件ずつの対照であり、二次翻訳ではありません**。
- **言語タグ**：`ja-JP` = 日本語（日本サーバー）。本ディレクトリの `target` 列は常に日本語の公式訳語で、
  `source` 列は `zh-CN`（簡体字）・`zh-TW`（繁体字）・`en-US`（英語）・`ko-KR`（韓国語）のいずれかです。
  中国語→日本語の片方向だけの用語表が欲しい場合は、`source` に中国語が入っている行だけを残してください。
- **文字コード**：UTF-8 with BOM + CRLF。Excel でダブルクリックしても文字化けしません。
  `_all.json` は UTF-8（BOM なし）です。
- **既知の制限**：
  - `05_技能描述关键术语` と `20_游戏机制` はテキストからの自動抽出（プレースホルダー分割＋
    全コーパス投票）によるもので、一部の項目は厳密な用語ではなく短い断片のままです。必要に応じて
    人手で確認してください；
  - ステージやイベントなど同名の多い項目はそれぞれ別行になり、項目をまたいだ統合は行っていません；
  - `02_干员异格` は異格形態そのもののみを収録しています。基本のオペレーターは `01_干员名称` を参照；
  - サーバーごとに実装時期が異なるため、まだ実装されていない内容は収録されません（同一 ID が
    2 言語以上に存在することを条件としています）。そのため `ja-JP` の一部の分類は `zh-CN` より
    行数が少なくなっています。
