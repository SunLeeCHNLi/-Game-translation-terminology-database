# 아크나이츠 용어집 — 한국어（`ko-KR`）

[← 게임 전체 설명으로 돌아가기](../README.md)

이 디렉터리는 **목표 언어를 `ko-KR`(한국어)로 하는** 용어집입니다. 각 행은 「다른 언어의 용어 →
한국어」 대응입니다. **13,950** 개 용어(20개 분류 용어 수의 합계, 분류를 넘어 중복을 제거하면
12,861개), **53,228** 행의 대조를 수록했습니다. `tgt_lng` 열은 항상 `ko-KR`이며, `source` 열에는
같은 용어의 나머지 4개 언어(`zh-CN` / `zh-TW` / `en-US` / `ja-JP`) 표기가 들어 있습니다.

## 파일

- `NN_<분류>.csv` — 모두 20개, 즉 `01_干员名称.csv` … `20_游戏机制.csv`.
  `source,target,tgt_lng` 3열이며 몰입형 번역 등 CAT / 용어 관리 도구에 바로 가져올 수 있습니다.
- `_all.json` — 위 20개 CSV를 합친 UTF-8(BOM 없음) JSON.
  구조는 `{"tgt_lng": "ko-KR", "categories": {"<분류>": [{"source","target","tgt_lng"}, …]}}` 이며
  20개 CSV와 동일한 53,228건의 대조를 담고 있습니다.
- 이 설명 파일 `README.md` 와 중국어 간체판 `README_zh-CN.md`.

> 분류 파일 이름은 모든 언어 디렉터리에서 중국어로 통일되어 있습니다(예: `01_干员名称.csv` = 오퍼레이터명).
> 언어를 넘어 분류를 맞추기 쉽고 스크립트가 일괄 처리하기 위해서입니다.

## 설명

- **번역 출처와 정렬 방식**: 모두 각 지역 서버 공식 클라이언트의 언팩 데이터 테이블
  (업스트림 `ArknightsGamedata` 저장소의 `kr` 구역 = 한국 서버)에서 가져왔습니다. 모든 테이블을
  항목 ID(`char_002_amiya`, `skchr_amiya_2` 등)로 키 삼아 5개 서버를 대조했으므로,
  **공식 현지화 텍스트를 한 건씩 맞춘 대조표이며 2차 번역이 아닙니다**.
- **언어 태그**: `ko-KR` = 한국어(한국 서버). 이 디렉터리의 `target` 열은 항상 한국어 공식 역어이고,
  `source` 열은 `zh-CN`(중국어 간체) / `zh-TW`(중국어 번체) / `en-US`(영어) / `ja-JP`(일본어) 중 하나입니다.
  중국어→한국어 단방향 용어표만 필요하면 `source` 에 중국어가 들어 있는 행만 남기면 됩니다.
- **인코딩**: UTF-8 with BOM + CRLF라 Excel에서 더블클릭해도 한자가 깨지지 않습니다.
  `_all.json` 은 UTF-8(BOM 없음)입니다.
- **알려진 제한**:
  - `05_技能描述关键术语` 와 `20_游戏机制` 는 텍스트 자동 추출(플레이스홀더 분할 + 전체 코퍼스 투표)
    결과라 일부 항목은 엄밀한 용어가 아니라 짧은 구절 조각입니다. 필요에 따라 사람이 검토하십시오;
  - 스테이지·이벤트처럼 이름이 겹치는 항목이 많은 분류는 각각 별도 행이 되며 항목 간 병합은 하지
    않았습니다;
  - `02_干员异格` 은 이격 형태 자체만 수록합니다. 기본 오퍼레이터는 `01_干员名称` 을 보십시오;
  - 서버마다 진행도가 달라 아직 실장되지 않은 내용은 수록되지 않습니다(같은 ID가 2개 언어 이상에
    존재해야 한다는 조건). 그래서 `ko-KR` 의 일부 분류는 `zh-CN` 보다 행수가 적습니다.
