# 《明日方舟》术语库 — 简体中文（`zh-CN`）

[← 返回游戏总说明](../README.md)

本目录是**以 `zh-CN`（简体中文）为目标语言**的术语库：每一条都是「其他语言词条 → 简体中文」的对照。
共 **14,101** 条词条（20 个分类词条数之和，跨分类去重后为 13,054 条）、**53,207** 行对照；
`tgt_lng` 列固定为 `zh-CN`，`source` 列收录同一词条在其余 4 种语言（`zh-TW` / `en-US` / `ja-JP` / `ko-KR`）中的写法。

## 文件

- `NN_<分类>.csv` — 共 20 个，即 `01_干员名称.csv` … `20_游戏机制.csv`。
  `source,target,tgt_lng` 三列，可直接导入沉浸式翻译等 CAT / 术语管理工具。
- `_all.json` — 上述 20 个 CSV 的合并版（UTF-8，无 BOM 的 JSON），
  结构为 `{"tgt_lng": "zh-CN", "categories": {"<分类>": [{"source","target","tgt_lng"}, …]}}`，
  共收录 53,207 条对照，内容与 20 个 CSV 完全一致。
- 本说明文件 `README.md`。

> 分类文件名在所有语言目录中保持中文（如 `01_干员名称.csv`），便于跨语言对照与脚本统一处理。

## 说明

- **译文来源与对齐方式**：全部来自各区服官方客户端解包数据表（上游 `ArknightsGamedata` 仓库的
  `cn` 区，即国服），所有表格以条目 ID（如 `char_002_amiya`、`skchr_amiya_2`）为键跨 5 个区服对齐，
  因此是**官方本地化文本的逐条对照，非二次翻译**。
- **语言标签**：`zh-CN` = 简体中文（国服）。本目录 `target` 列固定为简体中文官方译名；
  `source` 列可能来自 `zh-TW`（繁中）、`en-US`（英文）、`ja-JP`（日文）、`ko-KR`（韩文）任意一种。
  只想保留「英→中」单向词表时，只保留 `source` 为拉丁字母的行即可。
- **编码**：UTF-8 with BOM + CRLF，Excel 双击可直接打开且中文不乱码；
  `_all.json` 为 UTF-8（无 BOM）。
- **已知限制**：
  - `05_技能描述关键术语` 与 `20_游戏机制` 由文本自动挖掘（占位符分段 + 全语料投票），
    少数条目仍是短语片段而非严格术语，建议按需人工复核；
  - 关卡、活动等大量同名词条会各自成行，未做跨条目合并；
  - 干员异格仅收录异格形态本身，基础干员见 `01_干员名称`；
  - 由于各区服进度不同，日 / 英 / 韩 / 繁中尚未实装的最新内容不会出现在本目录中
    （生成时要求同一 ID 至少有两种语言存在）。
