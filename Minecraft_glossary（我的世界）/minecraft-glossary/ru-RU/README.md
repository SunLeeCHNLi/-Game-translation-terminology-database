# Глоссарий 我的世界（Minecraft） — Русский (`ru-RU`)

[← Вернуться к общему описанию игры](../../README.md)

Этот каталог — глоссарий, **целевой язык которого — русский (`ru-RU`)**.
В нём **101,629 строк соответствий** в **34 CSV-файлах** (34 категории: 19 в корне каталога
и 15 в `extra/`); столбец `tgt_lng` всегда равен `ru-RU`, а столбец `source` содержит написания
на остальных 13 языках. Целевые переводы взяты из **официальных языковых файлов Minecraft
Java Edition**, а не из повторного перевода.

## Файлы

- `<категория>.csv` (19 файлов) — три столбца `source,target,tgt_lng`, готовы к импорту в CAT-системы и глоссарии
- `extra/<категория>.csv` (15 файлов) — те же три столбца, для системных и текстовых категорий

## Примечания

- **Источник и выравнивание.** Термины извлечены из официальных языковых файлов Minecraft Java
  Edition (`assets/minecraft/lang/ru_ru.json` через [misode/mcmeta](https://github.com/misode/mcmeta)),
  то есть это официальная локализация. В каждом файле `target` — русский текст, а `source` — текст на
  **любом из остальных 13 языков**; один термин встречается по одному разу на каждый исходный язык
  (одинаковые строки, включая `source` = `target`, объединены).

- **Языковая метка.** `tgt_lng` всегда `ru-RU`, что соответствует официальному локалю `ru_ru`.

- **Кодировка.** Все CSV — **UTF-8 с BOM**, перевод строки **CRLF**, первая строка — заголовок; поля с
  запятой, кавычками или переводом строки экранированы по RFC 4180. BOM и CRLF позволяют открыть файлы
  в Excel двойным щелчком. Внимание: некоторые длинные текстовые поля содержат перевод строки внутри
  кавычек (около 2 000 полей на язык) — используйте парсер CSV, совместимый с RFC 4180, а не подсчёт
  строк файла.

- **Известные ограничения.** «Число строк соответствий» — это не «число терминов»: сумма `entries` по
  34 категориям равна 8,559 — это количество объектов игровых названий, отнесённых к категориям в
  официальных языковых файлах (включая записи, не переведённые на данный язык). Полное определение —
  в разделе «Data Overview» файла `../../README.md` в корне игры. Часть строк — это лишь тексты
  интерфейса (GUI, сетевая игра, Realms и т. д.), а не термины. Термины, оставшиеся в официальной
  локализации без перевода, строк не создают. Количество строк в 14 языковых папках немного различается,
  так как покрытие переводом у языков разное.

- **Воспроизведение.** `python tools/build_glossary.py` (из корня игры); скрипт читает внешний каталог
  данных. Полная таблица соответствия префиксов категориям находится в `CATEGORIES` этого скрипта.
