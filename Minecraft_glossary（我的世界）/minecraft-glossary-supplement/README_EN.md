# Minecraft Wiki Standard Translations Supplement Glossary

## [简体中文](README.md) [日本語](README_JP.md)

This directory is a **supplement glossary** to `minecraft-glossary/`, containing the standard translations from the [Minecraft Wiki 译名标准化](https://zh.minecraft.wiki/w/Minecraft_Wiki:译名标准化) page, used to supplement translations that the official language files do not cover or that differ from the Wiki standard.

## Data Sources

- [Minecraft Wiki:译名标准化](https://zh.minecraft.wiki/w/Minecraft_Wiki:译名标准化) (the Simplified Chinese / Traditional Chinese variants are scraped separately and then merged)
- That page is also the Wiki's source of translation norms; its translations are kept consistent with the official localization decisions already settled on Crowdin, and the in-game original text is used temporarily where nothing has been settled.

## Coverage

- This supplement glossary **covers only the two target languages `zh-CN` (Simplified Chinese) and `zh-TW` (Traditional Chinese)**; for other languages, please use the main glossary `minecraft-glossary/`.
- Within each language folder, the same entry appears once with `en-US` and once with the other Chinese variant as the `source`.

## File Format

The same as the main glossary: **UTF-8 (with BOM)**, **CRLF**, header row first.

| source | target | tgt_lng |
| --- | --- | --- |
| Chest | 箱子 | zh-CN |
| 儲物箱 | 箱子 | zh-CN |

## Differences from the Main Glossary

- Different classification systems: this supplement glossary is divided into 13 categories by the **sections** of the Wiki page (`advancements`, `biomes`, `blocks`, `effects`, `enchantments`, `entities`, `environment`, `game-content`, `game-modes`, `game-versions`, `items`, `other`, `technical`), which differ from the 34 categories of the main glossary `minecraft-glossary/` (19 main categories + 15 `extra/` categories) **in both names and scope**, so the two cannot be merged directly by category name.
- Chinese only: `zh-CN` rows use `en-US` and `zh-TW` as the `source`, and `zh-TW` rows use `en-US` and `zh-CN` as the `source`; the spellings of other languages are not included.
- The Wiki uses "台灣正體" wording (for example `Chest` = 儲物箱, `Slab` = 半磚, `Stairs` = 階梯), which may differ from the in-game Traditional Chinese language files, so the two sets of material are **best used as needed**.
- Entries marked as "do not translate" (such as `Mojang`, `Minecraft`) are not included in this glossary.
- When one English name corresponds to multiple Chinese spellings, the Wiki's spelling is used, joined with ` / ` (for example `Boolean` = 布林值 / 布林型).

## Usage Tips

- Regenerating: first scrape the two variants `zh-cn` / `zh-tw` of the page (`action=parse&prop=text&variant=...`), then run `tools/build_wiki_supplement.py`.
- This README is generated by `tools/make_readme.py`, and the numbers on this page come from `tools/supplement_counts.json`; please do not edit the numbers by hand.
