# 《貓之城》術語庫 — 繁體中文（`zh-TW`）

[← 返回遊戲總說明](../README.md)

本目錄是**以 `zh-TW` 為目標語言**的術語庫：每一條都是「其他語言詞條 → 繁體中文」的對照。
共 **101,915** 條詞條、**196,972** 行對照，`tgt_lng` 欄固定為 `zh-TW`；`source` 欄收錄其餘六種語言
（简体中文、English、日本語、한국어、ภาษาไทย、Bahasa Indonesia）的寫法。譯文全部來自遊戲官方已實裝
的本地化文本，依同一個文本鍵對齊，不含二次機翻。

## 檔案

- `01_character/01_character_glossary.csv` … `16_terminology/16_terminology_glossary.csv`
  —— `source,target,tgt_lng` 三欄，可直接匯入沉浸式翻譯等 CAT／術語管理工具；
- `01_character/01_character_terms.csv` … `16_terminology/16_terminology_terms.csv`
  —— 本語言詞條清單（`id,term,src_table`），方便校對與回查原始資料表；
- `00_master/index.csv` —— 本語言的分类索引與條數；
- `00_master/README.md` —— 本語言資料目錄的說明（中文）。
- 上游七語並排總表：`../multilingual/all_languages_master.csv`（102,213 條 × 10 欄）。

## 說明

- **譯文來源與對齊方式**：全部取自遊戲官方多語言資料表（`Setting/Data`）與 I18N 介面文本表
  （`Setting/I18N`）中已實裝的繁體中文文本，依同一個文本鍵對齊，非二次翻譯。
- **語言標籤說明**：`tgt_lng` 欄固定為 `zh-TW`；`source` 欄可能是任一其他語言的寫法，
  同一條詞條的不同語言寫法各佔一行。
- **編碼說明**：所有 CSV 均為 **UTF-8 with BOM + CRLF**，Excel 點兩下即可正確顯示。
- **已知限制**：
  - 分類依資料表自動歸類，個別跨玩法的通用文本可能歸入相鄰分類；
  - 官方資料表中敵人名稱未提供多語言欄，`06_enemy` 僅 27 條；
  - 文本中的佔位符（如 `_name_`、`_num_`、`\n`）保留官方原樣，未做替換；
  - 各語言覆蓋的文本鍵不完全一致（例如 `zh-TW` 比 `zh-CN` 少 298 條），故各語言條數不同；
  - 不同地區版本、遊戲版本之間可能存在譯名差異，本庫以所引用的資料包版本為準。
- **更新與複現**：本庫是純資料產品，遊戲目錄下**沒有 `tools/` 目錄、也沒有任何腳本**，
  生成流程以文字記錄在 `../README.md` 的「生成與複現」一節，沒有可直接執行的命令。
