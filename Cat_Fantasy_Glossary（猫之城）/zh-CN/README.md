# 《猫之城》术语库 — 简体中文（`zh-CN`）

[← 返回游戏总说明](../README.md)

本目录是**以 `zh-CN` 为目标语言**的术语库：每一条都是「其他语言词条 → 简体中文」的对照。
共 **102,213** 条词条、**196,870** 行对照，`tgt_lng` 列固定为 `zh-CN`；`source` 列收录其余六种语言
（繁體中文、English、日本語、한국어、ภาษาไทย、Bahasa Indonesia）的写法。译文全部来自游戏官方已实装
的本地化文本，按同一文本键对齐，不含二次机翻。

## 文件

- `01_character/01_character_glossary.csv` … `16_terminology/16_terminology_glossary.csv`
  —— `source,target,tgt_lng` 三列，可直接导入沉浸式翻译等 CAT / 术语管理工具；
- `01_character/01_character_terms.csv` … `16_terminology/16_terminology_terms.csv`
  —— 本语言词条清单（`id,term,src_table`），便于校对与回查原始数据表；
- `00_master/index.csv` —— 本语言的分类索引与条数（`category,label,term_count,glossary_count,glossary_file,terms_file,target_language`）；
- `00_master/README.md` —— 本语言数据目录的说明（中文）。
- 上游七语并排总表：`../multilingual/all_languages_master.csv`（102,213 条 × 10 列，源数据产品，不在本目录内）。

## 说明

- **译文来源与对齐方式**：全部取自游戏官方多语言数据表（`Setting/Data`）与 I18N 界面文本表
  （`Setting/I18N`）中已实装的中文文本，按同一文本键对齐；`zh-CN` 为原始语言（基准列，无语言后缀），
  因此本目录的 `source` 列不会出现与 `target` 相同的简体中文写法。
- **语言标签说明**：`tgt_lng` 列固定为 `zh-CN`，用于导入术语工具后标记目标语言；`source` 列可能是
  任一其他语言的写法，同一条词条的不同语言写法各占一行。
- **编码说明**：所有 CSV 均为 **UTF-8 with BOM + CRLF**，Excel 双击即可正确显示，无需手动指定编码。
- **已知限制**：
  - 分类按数据表自动归类，个别跨玩法的通用文本可能归入相邻分类；
  - 游戏数据表中敌人类名称未提供多语言列，`06_enemy` 仅 27 条；
  - 文本中的占位符（如 `_name_`、`_num_`、`#num_percent_0_1_1_`、`\n`）保留官方原样，未做替换；
  - 各语言覆盖的文本键并不完全一致，故各语言的词条数与对照行数不同；
  - 不同地区版本、游戏版本之间可能存在译名差异，本库以所引用的数据包版本为准。
- **更新与复现**：本库是纯数据产品，游戏目录下**没有 `tools/` 目录、也没有任何脚本**，
  生成流程以文字记录在 `../README.md` 的「生成与复现」一节，没有可直接执行的命令。
