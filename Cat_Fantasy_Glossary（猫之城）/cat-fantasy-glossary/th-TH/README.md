# คลังศัพท์ Cat Fantasy — ภาษาไทย (`th-TH`)

[← กลับไปยังคำอธิบายภาพรวมของเกม](../README.md)

ไดเรกทอรีนี้เป็นคลังศัพท์ที่**ใช้ `th-TH` เป็นภาษาเป้าหมาย** แต่ละแถวคือการเทียบ "คำศัพท์ภาษาอื่น → ภาษาไทย"
มีทั้งหมด **99,978** คำศัพท์ และ **191,726** แถวเทียบ โดยคอลัมน์ `tgt_lng` ถูกตรึงไว้ที่ `th-TH`
คอลัมน์ `source` บรรจุรูปแบบของอีก 6 ภาษา (จีนตัวย่อ จีนตัวเต็ม อังกฤษ ญี่ปุ่น เกาหลี อินโดนีเซีย)
คำแปลทั้งหมดนำมาจากข้อความโลคัลไลซ์ที่เกมเปิดใช้งานอย่างเป็นทางการ และจัดแนวด้วยคีย์ข้อความเดียวกัน
ไม่มีเครื่องแปลอัตโนมัติใด ๆ

## ไฟล์

- `01_character/01_character_glossary.csv` … `16_terminology/16_terminology_glossary.csv`
  —— สามคอลัมน์ `source,target,tgt_lng` นำเข้าเครื่องมือ CAT / จัดการศัพท์ เช่น Immersive Translation ได้ทันที

- `00_master/README.md` —— คำอธิบายไดเรกทอรีข้อมูลของภาษานี้ (ภาษาจีน)
- ตารางรวม 7 ภาษาต้นทาง: `../multilingual/all_languages_master.csv` (102,213 รายการ × 10 คอลัมน์)

## หมายเหตุ

- **ที่มาและวิธีจัดแนวคำแปล**: นำจากข้อความภาษาไทยที่เปิดใช้งานแล้วในตารางข้อมูลหลายภาษาทางการของเกม
  (`Setting/Data`) และตารางข้อความอินเทอร์เฟซ I18N (`Setting/I18N`) จัดแนวด้วยคีย์ข้อความเดียวกัน
  ไม่ใช่การแปลซ้ำ
- **แท็กภาษา**: คอลัมน์ `tgt_lng` ตรึงไว้ที่ `th-TH` คอลัมน์ `source` อาจเป็นรูปแบบของภาษาใดก็ได้
  โดยคำศัพท์รายการเดียวกันจะแยกเป็นหนึ่งแถวต่อหนึ่งภาษา
- **การเข้ารหัส**: ไฟล์ CSV ทั้งหมดเป็น **UTF-8 with BOM + CRLF** ดับเบิลคลิกใน Excel แล้วแสดงผลถูกต้อง
  โดยไม่ต้องระบุการเข้ารหัส
- **ข้อจำกัดที่ทราบ**:
  - หมวดหมู่เป็นการจัดอัตโนมัติตามตารางข้อมูล ข้อความทั่วไปที่ใช้ข้ามโหมดเล่นอาจอยู่ในหมวดหมู่ข้างเคียง
  - ตารางข้อมูลทางการไม่มีคอลัมน์หลายภาษาสำหรับชื่อศัตรู หมวด `06_enemy` จึงมีเพียง 27 รายการ
  - ตัวยึดตำแหน่งในข้อความ (เช่น `_name_`, `_num_`, `\n`) คงไว้ตามต้นฉบับทางการ ไม่ได้แทนที่
  - คีย์ข้อความที่แต่ละภาษาครอบคลุมไม่เหมือนกันทั้งหมด (เช่น `th-TH` ครอบคลุมน้อยกว่า `zh-CN` อยู่ 2,235
    รายการ) จึงทำให้จำนวนของแต่ละภาษาแตกต่างกัน
  - ชื่อแปลอาจแตกต่างกันตามเวอร์ชันภูมิภาคและเวอร์ชันเกม คลังนี้ยึดตามเวอร์ชันของแพ็กเกจข้อมูลที่อ้างอิงไว้
- **การอัปเดตและการทำซ้ำ**: คลังนี้เป็นผลผลิตข้อมูลล้วน ภายใต้ไดเรกทอรีเกม **ไม่มี `tools/`
  และไม่มีสคริปต์ใด ๆ** ขั้นตอนการสร้างบันทึกเป็นข้อความไว้ในหัวข้อ "การสร้างใหม่" ของ `../README.md`
  และไม่มีคำสั่งที่รันได้

## ข้อจำกัดความรับผิด

ไดเรกทอรีนี้เป็นคลังศัพท์คำแปลภาษาไทย**ที่ไม่เป็นทางการ** จัดทำและดูแลโดยบุคคลคนเดียว เพื่อใช้ใน
การศึกษา ค้นคว้าส่วนบุคคล และช่วยจับคู่ศัพท์ให้ซอฟต์แวร์แปลด้วย AI (รวมถึงแต่ไม่จำกัดเพียง
Immersive Translation) เท่านั้น คลังนี้ไม่มีความสัมพันธ์ใด ๆ ด้านสังกัด การอนุญาต ความร่วมมือ ตัวแทน
หรือการเป็นผู้แทนอย่างเป็นทางการกับผู้พัฒนา ผู้จัดจำหน่าย ผู้ให้บริการ หรือผู้ถือลิขสิทธิ์ของ
*Cat Fantasy* ชื่อแปลในคลังไม่ได้แสดงจุดยืนอย่างเป็นทางการ ไม่รับประกันว่าจะถูกต้อง ครบถ้วน หรือตรงกับ
เวอร์ชันปัจจุบันของเกมเสมอ และ**ไม่ควรถือเป็นอภิธานศัพท์ทางการหรือไฟล์โลคัลไลซ์ทางการ** ทรัพย์สินทางปัญญา
เช่น ชื่อเกม ชื่อตัวละคร คำวิสามัญ และเครื่องหมายการค้า เป็นของเจ้าของสิทธิ์แต่ละราย คลังนี้ไม่เรียกร้อง
สิทธิ์ใด ๆ เหนือทรัพย์สินทางปัญญาของบุคคลที่สามดังกล่าว ความรับผิดชอบทั้งหมดที่เกิดจากการใช้โครงการนี้
หรือผลลัพธ์การแปลที่เกิดจากโครงการนี้เป็นของผู้ใช้เอง ข้อกำหนดฉบับเต็มดูได้ที่
`README.md` / `README_EN.md` / `README_JP.md` ที่รากของที่เก็บ
