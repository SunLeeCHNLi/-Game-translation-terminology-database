# Cat Fantasy 用語集 — 日本語（`ja-JP`）

[← ゲーム全体の説明に戻る](../README.md)

本ディレクトリは**対象言語を `ja-JP` とする**用語集です。各行は「他言語の項目 → 日本語」の対照で、
**101,621** 件の項目と **196,919** 行の対照を収録し、`tgt_lng` 列は `ja-JP` に固定されています。
`source` 列には他の 6 言語（簡体字中国語、繁体字中国語、英語、韓国語、タイ語、インドネシア語）の
表記が入ります。訳語はすべてゲームが公式に実装しているローカライズテキストから取得し、同一の
テキストキーで整列したもので、機械翻訳は含みません。

## ファイル

- `01_character/01_character_glossary.csv` … `16_terminology/16_terminology_glossary.csv`
  —— `source,target,tgt_lng` の 3 列で、没入型翻訳などの CAT／用語管理ツールにそのまま読み込めます；
- `01_character/01_character_terms.csv` … `16_terminology/16_terminology_terms.csv`
  —— 本言語の項目リスト（`id,term,src_table`）。校正や元データテーブルの逆引きに便利です；
- `00_master/index.csv` —— 本言語の分類索引と件数；
- `00_master/README.md` —— 本言語データディレクトリの説明（中国語）。
- 上流の 7 言語並列総合テーブル：`../multilingual/all_languages_master.csv`（102,213 項目 × 10 列）。

## 説明

- **訳語の出典と整列方法**：ゲームの公式多言語データテーブル（`Setting/Data`）と I18N インターフェース
  テキストテーブル（`Setting/I18N`）に実装済みの日本語テキストから取得し、同一のテキストキーで
  整列しています。二次翻訳ではありません。
- **言語タグ**：`tgt_lng` 列は `ja-JP` に固定です。`source` 列には他言語の表記が入り、同じ項目の
  各言語表記が 1 行ずつ並びます。
- **文字コード**：すべての CSV は **UTF-8 with BOM + CRLF** です。Excel でダブルクリックすれば
  そのまま正しく表示されます。
- **既知の制限**：
  - 分類はデータテーブルによる自動分類のため、遊び方をまたぐ一部の共通テキストが隣接する分類に
    入ることがあります；
  - 公式データテーブルでは敵の名称に多言語列がないため、`06_enemy` は 27 件のみです；
  - テキスト内のプレースホルダー（`_name_`、`_num_`、`\n` など）は公式のまま保持し、置換していません；
  - 言語ごとに収録するテキストキーは完全には一致しません（例えば `ja-JP` は `zh-CN` より 592 件
    少ない）。そのため言語ごとに件数が異なります；
  - 地域版・ゲームバージョンによって訳名が異なる場合があります。本データベースは上記で参照した
    データパッケージのバージョンに準拠します。
- **更新と再現**：本データベースは純粋なデータ成果物です。ゲームディレクトリには **`tools/`
  ディレクトリもスクリプトも一切ありません**。生成手順は `../README.md` の「再生成」節に文章として
  記録されており、実行できるコマンドは存在しません。
