本文件夹是**以 `ja-JP` 为目标语言**的术语库：每一条都是「其他语言词条 → 日本語」的对照，
共 **101,621** 条词条、**196,919** 行对照（`tgt_lng` 列固定为 `ja-JP`）。

## 文件

- `NN_xxx/NN_xxx_glossary.csv` — `source,target,tgt_lng` 格式，可直接导入 CAT / 术语管理工具
- `NN_xxx/NN_xxx_terms.csv` — 本语言词条清单（`id,term,src_table`），便于校对与回查
- `00_master/index.csv` — 分类索引与条数
