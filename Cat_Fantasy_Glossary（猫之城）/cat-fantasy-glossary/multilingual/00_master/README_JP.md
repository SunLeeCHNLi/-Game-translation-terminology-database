# 七言語並列総表

## [简体中文](README.md) [English](README_EN.md)

`all_languages_master.csv` は全 **102,213** 語を「1 語 1 行」で 7 言語横並びに列挙し、全体検索や二次加工を容易にします。

| 列 | 説明 |
| --- | --- |
| `id` | 語彙 ID。形式は `取得元テーブル名.主キー.フィールド名` で、各言語の `*_terms.csv` の `id` と対応します |
| `category` | 所属分類（`source_mapping.csv` を参照） |
| `src_table` | 公式データパッケージ内の取得元テーブルの相対パス |
| `zh-CN` ~ `id-ID` | その語彙の各言語における公式テキスト。欠落している場合は空欄 |

## 収録内容

- `all_languages_master.csv` — 七言語並列総表
- `00_master/source_mapping.csv` — 取得元テーブル → 分類 の対応と語彙数（全 379 テーブル）

## 説明

- 本表は各言語版の**上流総表**であり、各言語ディレクトリ内の `*_glossary.csv` はここから展開して生成されます；
- 英語が `en_UK` と `en_US` の 2 系統ある場合、総表は `en_US` を優先し、欠落時は `en_UK` にフォールバックします。`en-US` ディレクトリと整合しています；
- 分類ごとに分割する場合は、各言語ディレクトリ内の分類ファイルをそのまま使用してください。
