# Cat Fantasy 用語集 / Cat Fantasy Terminology Database / 《猫之城》翻译术语库

## [中文](README.md) [English](README_EN.md)

本データベースは、モバイルゲーム『キャットファンタジー』（Cat Fantasy／《猫之城》）の公式多言語
テキストを、公式の多言語データテーブルと I18N インターフェーステキストテーブルから抽出・整列した
ものです。**102,213** 件の一意な項目を収録し、対象言語ごとに **7** セットの独立した用語集
（**619,095** 件の項目レコード、**1,206,381** 行の言語対照）に分割し、各セットをさらに 16 分類に
整理しています。訳語は**すべてゲームが公式に実装しているローカライズテキスト**から取得し、同一の
テキストキーで整列したもので、機械翻訳や二次的な翻訳は一切含みません。`zh-CN`／`zh-TW`／`en-US`／
`ja-JP`／`ko-KR`／`th-TH` の 6 セットは 16 分類すべてを収録し、`id-ID` はインドネシア語が公式に
インターフェーステキストにのみ実装されているため `13_ui` の 1 分類のみを収録しています。

## 使用方法

1. **単一ファイルのダウンロード** — 目的の言語ディレクトリ（例：`zh-CN/`）を開き、必要な分類の
   `NN_xxx_glossary.csv` を開いてファイル詳細ページから直接ダウンロードします。このファイルは
   `source,target,tgt_lng` の 3 列形式で、没入型翻訳（Immersive Translation）などの AI 翻訳
   ソフトの用語集機能にそのまま読み込めます。
2. **言語ディレクトリごとの一括ダウンロード** — 言語ディレクトリ内の 16 分類を合わせると、その
   言語の完全な用語集になります（分類索引と件数は同ディレクトリの `00_master/index.csv` を参照）。
3. **リポジトリ全体のクローン** — 各言語の `00_master/index.csv` と
   `multilingual/all_languages_master.csv` を使って検索・分割・二次加工を行えます。データの出典は
   後述の「使用した関連コンテンツ」を参照してください。**注意**：本データベースには生成スクリプトが
   含まれていません（「再生成」を参照）。

（用語対照表）と `NN_xxx_terms.csv`（その言語の項目リスト）です。また各言語ディレクトリには
`README.md`（その言語）と `README_zh-CN.md`（簡体字中国語）の 2 つの説明ファイルがあります
（`zh-CN/` は `README.md` のみ）。

> 大幅に少なくなっています。

### 公式言語サポートについて

本データベースの対象言語は**ゲームが公式に実装しているテキストに限られ**、後から機械翻訳を施した
ものはありません：

| 言語 | 状態 |
| --- | --- |
| `zh-CN` 簡体字中国語 | ✅ 公式実装（原語） |
| `zh-TW` 繁体字中国語 | ✅ 公式実装 |
| `en-US` English | ✅ 公式実装（下記の注記を参照） |
| `ja-JP` 日本語 | ✅ 公式実装 |
| `ko-KR` 한국어 | ✅ 公式実装 |
| `th-TH` ภาษาไทย | ✅ 公式実装 |
| `id-ID` Bahasa Indonesia | ✅ 公式実装（インターフェーステキストのみ） |
| `fr-FR` / `de-DE` / `es-ES` / `ru-RU` / `pt-BR` / `it-IT` / `tr-TR` / `vi-VN` | ❌ 公式未実装のため本データベースでは提供しません |

**英語について**：ゲームのデータテーブルには英語列が `en_UK` の 1 つのみですが、I18N テキスト
テーブルには `en_UK` と `en_US` の 2 系統の英語が存在します。本データベースの `en-US` ディレクトリ
では、実体名称は `en_UK` 列から取得し、インターフェーステキストは `en_US` を優先し、欠落時は
`en_UK` にフォールバックしています。2 系統の英語の原文はいずれも
`multilingual/all_languages_master.csv` の対応する列に保存されています。

### ファイル形式

各分類フォルダ内の 2 ファイルはいずれも **UTF-8 with BOM + CRLF** で保存されています（Excel で
ダブルクリックすればそのまま正しく開けます）。

**`NN_xxx_glossary.csv` — 用語対照表（`source` / `target` / `tgt_lng`）**

その言語の `tgt_lng` 列は固定で、`source` 列には他の言語の表記が入ります（同じ項目の各言語表記が
1 行ずつ）。没入型翻訳などの用語ツールにそのまま読み込めます：

| source | target | tgt_lng |
| --- | --- | --- |
| Asura | 非天 | zh-CN |
| アスラ | 非天 | zh-CN |
| 아수라 | 非天 | zh-CN |

**`NN_xxx_terms.csv` — その言語の項目リスト（`id` / `term` / `src_table`）**

| id | term | src_table |
| --- | --- | --- |
| Card.101002.name | 非天 | Card/Card.txt |
| Card.101002.desc | 非天 | Card/Card.txt |

- `id` = `元テーブル名.主キー.フィールド名` で、これによりゲームの元データテーブルを逆引きできます；
- `src_table` = 公式データパッケージ内でのその項目の相対パス（`MasterData\Setting\Data\` の下）。

**`00_master/index.csv`** はその言語の分類索引と件数です（列は
`category,label,term_count,glossary_count,glossary_file,terms_file,target_language`）。ここにある
16 分類をすべて統合すると、その言語の完全な用語集になります。

## 再生成

**本ディレクトリにはスクリプトが一切なく、`tools/` ディレクトリもありません。** これは**純粋な
データ成果物**であり、リポジトリ内に生成パイプラインのコードを同梱していないため、実行できる再現
コマンドは存在しません。生成手順は文章として以下に記録します（上流パッケージに対して再現したい方が
参照できるようにするためです）：

```text
# 本データベースにはスクリプトも tools/ ディレクトリもないため、実行できるコマンドはありません。
# 生成手順（データ整理の記録）：
1. Setting/Data 配下の全データテーブルを走査し、_zh_TW / _en_UK / _ja_JP / _ko_KR / _th_TH の
   接尾辞を持つ多言語フィールドを識別する。基準列（接尾辞なし）が zh-CN 原文。
2. データテーブルが属する遊び方のモジュールごとに 16 分類へ割り当てる（対応は
   multilingual/00_master/source_mapping.csv、全 379 テーブル）。
3. 13_ui 分類は Setting/I18N のハッシュテキストテーブルから取得し、Id キーで 7 言語を整列する。
4. NewChapter（ストーリーテーブル）からは登場キャラクター名やシーン名などの固有名詞のみを抽出し、
   ストーリー本文の会話は用語集に含めない。
5. 同一分類内で (source, target) により重複を排除する。原文と訳文の表記が完全に同一の場合は
   対照行を生成しない。
6. 各言語の *_glossary.csv は multilingual/all_languages_master.csv から分類ごとに展開して生成する。

# 再現する場合のデータ取得：
#   上流パッケージは上記「使用した関連コンテンツ」を参照し、各自で Setting/Data と Setting/I18N を
#   ダウンロードしてください。
# 本データベースを検証する場合は読み取り専用で直接参照できます（変更しないでください）：
#   zh-CN/00_master/index.csv                 言語別の分類索引と件数
#   multilingual/all_languages_master.csv     7 言語並列の総合テーブル
#   multilingual/00_master/source_mapping.csv 元テーブル → 分類 の対応
```

各セットは**同一のテキストキーで整列**した公式テキストであり、二次翻訳ではありません。1 つの項目が
他の言語の表記をすべて対照行として展開するため、「`zh-CN` → 他言語」の逆引き表としても使えます。

## 既知の制限

- 分類はデータテーブルによる自動分類のため、一部の項目（遊び方をまたぐ共通テキストなど）が隣接する
  分類に入ることがあります；
- ゲームのデータテーブルでは敵の名称に多言語列がないため、`06_enemy` 分類の件数はごくわずかです
  （`zh-CN` で 27 件のみ）；
- `id-ID` は `13_ui` の 1 分類のみで、残り 15 分類の CSV はヘッダー行のみでデータ行がありません；
- テキスト内のプレースホルダー（`_name_`、`_num_`、`#num_percent_0_1_1_`、`\n` など）は公式のまま
  保持しており、置換していません；
- 言語ごとに収録するテキストキーは完全には一致しません（例えば `th-TH` は 99,978 件、`id-ID` は
  インターフェーステキストのみ）。そのため言語ごとに項目数と対照行数が異なりますが、これは正常です；
- 地域版・ゲームバージョンによって訳名が異なる場合があります。本データベースは上記で参照した
  データパッケージのバージョンに準拠します。
