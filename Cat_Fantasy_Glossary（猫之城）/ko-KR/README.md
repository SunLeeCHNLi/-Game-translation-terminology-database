# Cat Fantasy 용어집 — 한국어 (`ko-KR`)

[← 게임 전체 설명으로 돌아가기](../README.md)

이 디렉터리는 **대상 언어가 `ko-KR`인** 용어집입니다. 각 행은 "다른 언어 항목 → 한국어" 대응이며,
**101,760**개 항목과 **197,663**행 대응을 수록하고 `tgt_lng` 열은 `ko-KR`로 고정되어 있습니다.
`source` 열에는 나머지 6개 언어(중국어 간체, 중국어 번체, 영어, 일본어, 태국어, 인도네시아어)의 표기가
들어갑니다. 모든 번역은 게임이 공식적으로 구현한 현지화 텍스트에서 가져와 동일한 텍스트 키로 정렬한
것이며, 기계 번역은 포함되지 않습니다.

## 파일

- `01_character/01_character_glossary.csv` … `16_terminology/16_terminology_glossary.csv`
  —— `source,target,tgt_lng` 3개 열로, 몰입형 번역 등 CAT／용어 관리 도구에 바로 가져올 수 있습니다;
- `01_character/01_character_terms.csv` … `16_terminology/16_terminology_terms.csv`
  —— 이 언어의 항목 목록(`id,term,src_table`)으로, 교정과 원본 데이터 테이블 역추적에 편리합니다;
- `00_master/index.csv` —— 이 언어의 분류 색인과 건수;
- `00_master/README.md` —— 이 언어 데이터 디렉터리 설명(중국어).
- 상위 7개 언어 병렬 통합 표: `../multilingual/all_languages_master.csv`(102,213개 항목 × 10개 열).

## 설명

- **번역 출처와 정렬 방식**: 게임의 공식 다국어 데이터 테이블(`Setting/Data`)과 I18N 인터페이스 텍스트
  테이블(`Setting/I18N`)에 이미 구현된 한국어 텍스트에서 가져와 동일한 텍스트 키로 정렬했습니다.
  이차 번역이 아닙니다.
- **언어 태그**: `tgt_lng` 열은 `ko-KR`로 고정입니다. `source` 열에는 다른 언어의 표기가 들어가며,
  같은 항목의 언어별 표기가 각각 한 행씩 들어갑니다.
- **인코딩**: 모든 CSV는 **UTF-8 with BOM + CRLF**이며, Excel에서 두 번 클릭하면 바로 올바르게
  표시됩니다.
- **알려진 제한**:
  - 분류는 데이터 테이블에 따른 자동 분류이므로, 콘텐츠를 가로지르는 일부 공통 텍스트가 인접 분류에
    들어갈 수 있습니다;
  - 공식 데이터 테이블에는 적 이름의 다국어 열이 없어 `06_enemy`는 27개뿐입니다;
  - 텍스트 내 자리표시자(`_name_`, `_num_`, `\n` 등)는 공식 원문 그대로 유지하며 치환하지 않았습니다;
  - 언어별로 수록하는 텍스트 키가 완전히 같지는 않습니다(예: `ko-KR`은 `zh-CN`보다 453개 적음).
    따라서 언어마다 건수가 다릅니다;
  - 지역 버전과 게임 버전에 따라 역명이 다를 수 있습니다. 이 데이터베이스는 위에서 참조한 데이터
    패키지 버전을 기준으로 합니다.
- **갱신과 재현**: 이 데이터베이스는 순수한 데이터 산출물입니다. 게임 디렉터리에는 **`tools/`
  디렉터리도, 어떤 스크립트도 없습니다.** 생성 절차는 `../README.md`의 "재생성" 절에 글로 기록되어
  있으며, 실행할 수 있는 명령은 없습니다.

## 면책 조항

이 디렉터리는 개인이 정리·유지하는 **비공식** 한국어 번역 용어 데이터베이스로, 개인적인 학습, 연구,
그리고 AI 번역 소프트웨어(몰입형 번역을 포함하되 이에 한정하지 않음)의 용어 매칭 보조만을 목적으로
합니다. 이 데이터베이스는 『캣 판타지』의 개발사, 퍼블리셔, 유통사, 운영사, 권리자와 어떠한 소속,
허가, 제휴, 대리 또는 공식 대표 관계도 없습니다. 수록된 역명은 공식 입장을 나타내지 않으며, 항상
정확하거나 완전하거나 게임의 현재 버전과 일치함을 보장하지 않고, **공식 용어집이나 공식 현지화
파일로 간주되어서는 안 됩니다.** 게임 이름, 캐릭터 이름, 고유명사, 상표 등 지식 재산권은 각 권리자에게
귀속되며, 이 데이터베이스는 이러한 제3자 지식 재산권에 대해 어떠한 권리도 주장하지 않습니다.
이 프로젝트와 그로부터 생성된 번역 결과의 사용으로 발생하는 모든 책임은 사용자 본인이 부담합니다.
전체 조항은 저장소 루트의 `README.md` / `README_EN.md` / `README_JP.md`를 참조하십시오.
