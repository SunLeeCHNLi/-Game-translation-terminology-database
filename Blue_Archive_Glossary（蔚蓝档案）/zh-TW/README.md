# 《蔚藍檔案》術語庫 — 繁體中文（`zh-TW`）

[← 返回遊戲總說明](../README.md)

本資料夾是**以 `zh-TW`（繁體中文）為目標語言**的術語庫：每一條都是「其他語言寫法 → 繁體中文」的對照，共 **6036** 條詞條、**27453** 行對照，`tgt_lng` 欄固定為 `zh-TW`，`source` 欄收錄 `zh-CN` / `en-US` / `ja-JP` / `ko-KR` / `th-TH` 五種語言裡同一詞條的寫法。需要每一詞條六語並排的完整檢視，請見 `00_master/README.md` 與 `../multilingual/00_master/`。

## 檔案

- `01_xxx/01_xxx_glossary.csv` — `source,target,tgt_lng` 三欄，可直接匯入 CAT / 術語管理工具
- `01_xxx/01_xxx_terms.csv` — 本語言詞條清單（`id,term,src_table`），適合校對與回查
- `00_master/all_glossary.csv` — 全部 15 個分類的對照行合併總表（`category,source,target,tgt_lng`）
- `00_master/all_terms.csv` — 本語言全部詞條清單（`category,category_label,id,term,src_table`）
- `00_master/index.csv` — 分類索引與條數（`category,label,term_count,glossary_file,terms_file,target_language`）
- `00_master/README.md` — 本語言庫的既有詳細說明

`01_xxx/` 是 15 個分類資料夾，每個資料夾下只有上面兩個檔案。

## 說明

- **譯文來源與對齊方式**：譯文全部取自官方客戶端多語言文本（國服 / 國際服 / 日服 / 韓服 / 泰服）與社群劇情對照表，按同一文本鍵（官方資料的 Id 或鍵名）對齊，屬於**官方在地化**而非二次翻譯；每條詞條會把其餘語言的寫法全部展開為對照行，因此本資料夾也可反向當作「繁體中文 → 其他語言」查詢。
- **語言標籤**：本庫出現的六種標籤為 `zh-CN` 簡體中文（國服）、`zh-TW` 繁體中文（國際服）、`en-US` English、`ja-JP` 日本語、`ko-KR` 한국어、`th-TH` ภาษาไทย；本資料夾的 `tgt_lng` 一律為 `zh-TW`。
- **`zh-CN` 與 `zh-TW` 是兩套不同的官方在地化**：譯名並非總是只差繁簡，同一個詞在學校短名與全名之間也可能不同（例如 `Gehenna`：簡中短名「格黑娜」、全名「歌赫娜」，繁中全名「格黑娜學園」）。
- **編碼**：所有 CSV 為 UTF-8 with BOM、CRLF 換行，Excel 按兩下即可正確顯示中日韓泰文字；本說明檔案為 UTF-8（無 BOM）。
- **已知限制**：
  - `04_story_title`、`06_location`、`09_scenario_character` 以劇情與社群資料為底，只在官方表出現**完全相同的寫法**時才自動補齊語種，因此並非每條都六語齊全（本資料夾 `06_location` 僅 8 條、`08_event` 僅 45 條、`09_scenario_character` 僅 134 條，明顯少於簡中 / 日文的覆蓋）；
  - 角色分類另附「全名」條目（姓＋名），僅中日韓三種語言：英文與泰文的姓名順序與中日韓相反，官方資料沒有給出可直接拼接的寫法；
  - `10_enemy` 為 349 條、`15_stage` 為 568 條，同樣少於官方表覆蓋較全的語言，屬於同一補齊機制的結果；
  - 與目標語言寫法完全相同的條目不會寫入術語表，同一名稱的多筆資料（例如不同等級的同名敵人）會合併為一條；
  - 極少數詞條（約 1%–3%）在**同一個目標語言檔案內**出現一條 `source` 對應多個 `target`，多來自同名不同物的短詞或簡繁兩套客戶端寫法並存。按 `source` 去重的工具只會保留其中一條，需要區分時請用 `_terms.csv` 裡的 `id` 與 `src_table` 回查上下文。
