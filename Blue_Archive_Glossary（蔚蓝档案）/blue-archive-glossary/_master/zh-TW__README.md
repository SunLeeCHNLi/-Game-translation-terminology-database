# 《蔚藍檔案》Blue Archive 術語庫 — 繁體中文（`zh-TW`）

本資料夾是**以 `zh-TW` 為目標語言**的術語庫：每一條都是「其他語言詞條 → 繁體中文」的對照，
共 **6036** 條詞條、27453 行對照（`tgt_lng` 欄固定為 `zh-TW`）。

## 檔案

- `NN_xxx/NN_xxx_glossary.csv` — `source,target,tgt_lng` 格式，可直接匯入 CAT / 術語管理工具
- `NN_xxx/NN_xxx_terms.csv` — 本語言詞條清單（`id, term, src_table`），適合校對與回查
- `00_master/all_glossary.csv` — 全部 15 個分類的合併術語表
- `00_master/all_terms.csv` — 本語言全部詞條清單
- `00_master/index.csv` — 分類索引與條數

上一層的 `../README.md` 是本語言庫的完整總說明。

## 說明

- 譯文全部取自官方客戶端多語言文本（國服 / 國際服 / 日服 / 韓服 / 泰服）與社群劇情對照表，按同一文本鍵對齊，非二次翻譯；
- 每條詞條會把其他語言的寫法全部展開為對照行，因此也可反向當作「zh-TW → 其他語言」查詢；
- 六種語言的標籤：`zh-CN` 簡體中文、`zh-TW` 繁體中文、`en-US` 英文、`ja-JP` 日文、`ko-KR` 韓文、`th-TH` 泰文；
- 極少數詞條會出現一條 `source` 對應多個 `target` 的情況（多為同名不同物的短詞，或簡繁兩套客戶端寫法並存）；按 `source` 去重的工具只會保留其中一條，需要區分時請用 `_terms.csv` 裡的 `id` 與 `src_table` 回查上下文；
- 檔案編碼為 UTF-8 with BOM，Excel 按兩下即可正確顯示中日韓泰文字。
