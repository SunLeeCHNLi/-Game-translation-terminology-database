# 六言語並列総表

## [简体中文](README.md) [English](README_EN.md)

15 分類の全 **7535** 語を「1 語 1 行」で並べて表示し、横断的な比較や二次加工を容易にします。

## ファイル

- `00_master/all_terms_multilingual.csv` — 全語彙
- `NN_xxx/NN_xxx_multilingual.csv` — 単一分類の語彙

## 列

| 列 | 説明 |
| --- | --- |
| `category` | 分類コード。例：`01_character` |
| `category_label` | 分類の中国語名 |
| `id` | 語彙 ID（公式データの Id / キー名に対応） |
| `zh-CN` | 簡体字中国語 |
| `ja-JP` | 日本語 |
| `zh-TW` | 繁体字中国語 |
| `en-US` | 英語 |
| `ko-KR` | 韓国語 |
| `th-TH` | タイ語 |
| `src_table` | その語彙の取得元テーブル |

空欄は、その言語に対応する表記が見つからなかったことを示します。目標言語ごとに分けて使う場合は、
一つ上のディレクトリにある対応する言語フォルダーをそのまま利用してください。
