# 《蔚蓝档案》术语库 — 简体中文（`zh-CN`）

[← 返回游戏总说明](../README.md)

本文件夹是**以 `zh-CN`（简体中文）为目标语言**的术语库：每一条都是「其他语言写法 → 简体中文」的对照，共 **7477** 条词条、**29463** 行对照，`tgt_lng` 列固定为 `zh-CN`，`source` 列收录 `zh-TW` / `en-US` / `ja-JP` / `ko-KR` / `th-TH` 五种语言里同一词条的写法。需要每一条目六语并排的完整视图，请见 `00_master/README.md` 与 `../multilingual/00_master/`。

## 文件

- `01_xxx/01_xxx_glossary.csv` — `source,target,tgt_lng` 三列，可直接导入 CAT / 术语管理工具
- `01_xxx/01_xxx_terms.csv` — 本语言词条清单（`id,term,src_table`），适合校对与回查
- `00_master/all_glossary.csv` — 全部 15 个分类的对照行合并总表（`category,source,target,tgt_lng`）
- `00_master/all_terms.csv` — 本语言全部词条清单（`category,category_label,id,term,src_table`）
- `00_master/index.csv` — 分类索引与条数（`category,label,term_count,glossary_file,terms_file,target_language`）
- `00_master/README.md` — 本语言库的既有详细说明

`01_xxx/` 是 15 个分类目录，每个目录下只有上面两个文件。

## 说明

- **译文来源与对齐方式**：译文全部取自官方客户端多语言文本（国服 / 国际服 / 日服 / 韩服 / 泰服）与社区剧情对照表，按同一文本键（官方数据的 Id 或键名）对齐，属于**官方本地化**而非二次翻译；每条词条会把其余语言的写法全部展开为对照行，因此本目录也可反向当作「简体中文 → 其他语言」查询。
- **语言标签**：本库出现的六种标签为 `zh-CN` 简体中文（国服）、`zh-TW` 繁体中文（国际服）、`en-US` English、`ja-JP` 日本語、`ko-KR` 한국어、`th-TH` ภาษาไทย；本目录的 `tgt_lng` 一律为 `zh-CN`。
- **编码**：所有 CSV 为 UTF-8 with BOM、CRLF 换行，Excel 双击即可正确显示中日韩泰文字；本说明文件为 UTF-8（无 BOM）。
- **已知限制**：
  - `04_story_title`、`06_location`、`09_scenario_character` 以剧情与社区资料为底，只在官方表出现**完全相同的写法**时才自动补齐语种，因此并非每条都六语齐全（本目录 `06_location` 有 90 条、`08_event` 有 72 条，而部分其他语言只覆盖 8 条 / 45 条）；
  - 角色分类另附「全名」条目（姓＋名），仅中日韩三种语言：英文与泰文的姓名顺序与中日韩相反，官方数据没有给出可直接拼接的写法；
  - 与目标语言写法完全相同的条目不会写入术语表，同一名称的多条数据（例如不同等级的同名敌人）会合并为一条；
  - 极少数词条（约 1%–3%）在**同一个目标语言文件内**出现一条 `source` 对应多个 `target`，多来自同名不同物的短词（例如 `Normal` 既是装甲类型也是道具稀有度）。按 `source` 去重的工具只会保留其中一条，需要区分时请用 `_terms.csv` 里的 `id` 与 `src_table` 回查上下文。
