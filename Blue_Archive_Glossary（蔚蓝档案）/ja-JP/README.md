# ブルーアーカイブ 用語集 — 日本語（`ja-JP`）

[← ゲーム全体の説明に戻る](../README.md)

このフォルダは**対象言語を `ja-JP`（日本語）とする用語集**です。各行は「他言語での表記 → 日本語」の対訳で、**7534** 項目・**29216** 行の対訳を含みます。`tgt_lng` 列は常に `ja-JP` で、`source` 列には `zh-CN` / `zh-TW` / `en-US` / `ko-KR` / `th-TH` の 5 言語における同一項目の表記が入ります。各項目を 6 言語並列で見たい場合は `00_master/README.md` と `../multilingual/00_master/` を参照してください。

## ファイル

- `01_xxx/01_xxx_glossary.csv` — `source,target,tgt_lng` の 3 列。CAT / 用語管理ツールにそのままインポートできます
- `01_xxx/01_xxx_terms.csv` — 本言語の項目リスト（`id,term,src_table`）。校正や突き合わせに適します
- `00_master/all_glossary.csv` — 15 分類すべての対訳行を統合したマスター表（`category,source,target,tgt_lng`）
- `00_master/all_terms.csv` — 本言語の全項目リスト（`category,category_label,id,term,src_table`）
- `00_master/index.csv` — 分類索引と件数（`category,label,term_count,glossary_file,terms_file,target_language`）
- `00_master/README.md` — この用語集の既存の詳細説明

`01_xxx/` は 15 の分類フォルダで、各フォルダには上記 2 ファイルだけが入っています。

## 説明

- **訳語の出典と対応付け**：訳語はすべて公式クライアントの多言語テキスト（中国版 / グローバル版 / 日本版 / 韓国版 / タイ版）とコミュニティのストーリー対訳表から取得し、同一のテキストキー（公式データの Id またはキー名）で対応付けています。**公式ローカライズ**であり二次翻訳ではありません。各項目は他言語の表記をすべて対訳行として展開するため、本フォルダは「日本語 → 他言語」の逆引きとしても使えます。
- **言語タグ**：本データベースで使う 6 つのタグは `zh-CN` 簡体字中国語（中国版）、`zh-TW` 繁体字中国語（グローバル版）、`en-US` 英語、`ja-JP` 日本語、`ko-KR` 韓国語、`th-TH` タイ語です。本フォルダの `tgt_lng` はすべて `ja-JP` です。
- **文字コード**：すべての CSV は UTF-8 with BOM、改行は CRLF で、Excel でダブルクリックすれば日中韓・タイ文字も正しく表示されます。本説明ファイルは UTF-8（BOM なし）です。
- **既知の制限**：
  - `04_story_title`、`06_location`、`09_scenario_character` はストーリーとコミュニティ資料を土台にしており、公式表と**完全に同一の表記**がある場合のみ他言語を自動補完するため、全項目が 6 言語そろっているわけではありません。本フォルダは日本語側のカバー率が高く、`06_location` は 90 項目、`08_event` は 72 項目あります。
  - キャラクター分類には「氏名（姓＋名）」の項目を別途収録していますが、これは日中韓の 3 言語のみです。英語とタイ語は姓名の順序が日中韓と逆で、公式データにそのまま連結できる表記がないためです。
  - 対象言語と表記が完全に同じ項目は用語集に書き込みません。同じ名称に複数のデータがある場合（例：レベル違いの同名の敵）は 1 項目に統合します。
  - ごく少数の項目（約 1%–3%）では、**この対象言語ファイル内**で 1 つの `source` が複数の `target` に対応します。同名異物の短い語（例：`Normal` は装甲タイプでもありアイテムのレアリティでもある）によるものです。`source` で重複排除するツールは 1 件しか残しませんので、区別が必要な場合は `_terms.csv` の `id` と `src_table` で文脈を確認してください。
