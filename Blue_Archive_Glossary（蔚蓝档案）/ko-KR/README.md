# 블루 아카이브 용어집 — 한국어（`ko-KR`）

[← 게임 전체 설명으로 돌아가기](../README.md)

이 폴더는 **대상 언어를 `ko-KR`（한국어）로 하는 용어집**입니다. 각 행은 「다른 언어의 표기 → 한국어」 대역이며, **7310** 개 항목과 **29009** 행의 대역을 담고 있습니다. `tgt_lng` 열은 항상 `ko-KR`이고, `source` 열에는 `zh-CN` / `zh-TW` / `en-US` / `ja-JP` / `th-TH` 다섯 언어에서 같은 항목의 표기가 들어갑니다. 항목별 6개 언어 병렬 보기는 `00_master/README.md` 와 `../multilingual/00_master/` 를 참고하십시오.

## 파일

- `01_xxx/01_xxx_glossary.csv` — `source,target,tgt_lng` 3개 열. CAT / 용어 관리 도구에 그대로 가져올 수 있습니다
- `01_xxx/01_xxx_terms.csv` — 이 언어의 항목 목록(`id,term,src_table`). 교정과 대조에 적합합니다
- `00_master/all_glossary.csv` — 15개 분류 전체의 대역 행을 합친 마스터 표(`category,source,target,tgt_lng`)
- `00_master/all_terms.csv` — 이 언어의 전체 항목 목록(`category,category_label,id,term,src_table`)
- `00_master/index.csv` — 분류 색인과 개수(`category,label,term_count,glossary_file,terms_file,target_language`)
- `00_master/README.md` — 이 용어집의 기존 상세 설명

`01_xxx/` 는 15개 분류 폴더이며, 각 폴더에는 위 두 파일만 들어 있습니다.

## 설명

- **번역 출처와 정렬 방식**: 번역은 모두 공식 클라이언트의 다국어 텍스트(중국 서버 / 글로벌 서버 / 일본 서버 / 한국 서버 / 태국 서버)와 커뮤니티 스토리 대역표에서 가져왔고, 동일한 텍스트 키(공식 데이터의 Id 또는 키 이름)로 정렬했습니다. 따라서 **공식 현지화**이며 2차 번역이 아닙니다. 각 항목은 다른 언어의 표기를 모두 대역 행으로 펼치므로, 이 폴더는 「한국어 → 다른 언어」 역방향 조회에도 쓸 수 있습니다.
- **언어 태그**: 이 데이터베이스에서 쓰는 여섯 태그는 `zh-CN` 중국어 간체(중국 서버), `zh-TW` 중국어 번체(글로벌 서버), `en-US` 영어, `ja-JP` 일본어, `ko-KR` 한국어, `th-TH` 태국어입니다. 이 폴더의 `tgt_lng` 는 모두 `ko-KR` 입니다.
- **인코딩**: 모든 CSV는 UTF-8 with BOM, 줄바꿈은 CRLF이므로 Excel에서 두 번 클릭하면 한중일 및 태국 문자가 올바르게 표시됩니다. 이 설명 파일은 UTF-8(BOM 없음)입니다.
- **알려진 제한**:
  - `04_story_title`, `06_location`, `09_scenario_character` 는 스토리와 커뮤니티 자료를 바탕으로 하며, 공식 표에 **완전히 같은 표기**가 있을 때만 다른 언어를 자동으로 채우므로 모든 항목이 6개 언어로 갖춰져 있지는 않습니다(이 폴더는 `06_location` 8개, `08_event` 45개로, 중국어 간체 / 일본어의 90개 / 72개보다 적습니다).
  - 캐릭터 분류에는 「전체 이름」(성 + 이름) 항목이 별도로 있지만 한중일 세 언어에만 있습니다. 영어와 태국어는 이름 순서가 한중일과 반대이고, 공식 데이터에 바로 이어 붙일 수 있는 표기가 없기 때문입니다.
  - 대상 언어와 표기가 완전히 같은 항목은 용어집에 쓰지 않고, 같은 이름에 여러 데이터가 있는 경우(예: 레벨만 다른 동명의 적)에는 한 항목으로 합칩니다.
  - 아주 적은 수의 항목(약 1%–3%)은 **이 대상 언어 파일 안에서** 하나의 `source` 가 여러 `target` 에 대응합니다. 같은 이름이 다른 것을 가리키는 짧은 단어(예: `Normal` 은 장갑 유형이면서 아이템 희귀도이기도 함) 때문입니다. `source` 로 중복을 제거하는 도구는 한 건만 남기므로, 구분이 필요하면 `_terms.csv` 의 `id` 와 `src_table` 로 문맥을 확인하십시오.
