# คลังศัพท์ Blue Archive — ภาษาไทย (`th-TH`)

[← กลับไปยังคำอธิบายระดับเกม](../README.md)

โฟลเดอร์นี้เป็น**คลังศัพท์ที่ใช้ `th-TH` (ภาษาไทย) เป็นภาษาปลายทาง** ทุกแถวเป็นการเทียบ「คำในภาษาอื่น → ภาษาไทย」 มีทั้งหมด **5908** คำ และ **26478** แถวการเทียบ โดยคอลัมน์ `tgt_lng` เป็น `th-TH` เสมอ และคอลัมน์ `source` เก็บคำของคำเดียวกันจากอีก 5 ภาษา ได้แก่ `zh-CN` / `zh-TW` / `en-US` / `ja-JP` / `ko-KR` หากต้องการมุมมอง 6 ภาษาแบบเทียบเคียงทีละคำ โปรดดู `00_master/README.md` และ `../multilingual/00_master/`

## คำอธิบาย

- **ที่มาและวิธีจับคู่คำแปล**: คำแปลทั้งหมดนำมาจากข้อความหลายภาษาของไคลเอนต์อย่างเป็นทางการ (เซิร์ฟเวอร์จีน / เซิร์ฟเวอร์สากล / เซิร์ฟเวอร์ญี่ปุ่น / เซิร์ฟเวอร์เกาหลี / เซิร์ฟเวอร์ไทย) และตารางเทียบเนื้อเรื่องจากชุมชน โดยจับคู่ด้วยคีย์ข้อความเดียวกัน (Id หรือชื่อคีย์ในข้อมูลอย่างเป็นทางการ) จึงเป็น**การแปลอย่างเป็นทางการ (official localization)** ไม่ใช่การแปลทอด แต่ละคำจะกระจายคำของภาษาที่เหลือทั้งหมดเป็นแถวการเทียบ โฟลเดอร์นี้จึงใช้ค้นย้อนกลับแบบ「ภาษาไทย → ภาษาอื่น」ได้ด้วย
- **แท็กภาษา**: แท็กทั้งหกที่ใช้ในคลังนี้คือ `zh-CN` จีนตัวย่อ (เซิร์ฟเวอร์จีน), `zh-TW` จีนตัวเต็ม (เซิร์ฟเวอร์สากล), `en-US` อังกฤษ, `ja-JP` ญี่ปุ่น, `ko-KR` เกาหลี และ `th-TH` ไทย โดย `tgt_lng` ในโฟลเดอร์นี้เป็น `th-TH` ทั้งหมด
- **การเข้ารหัส**: ไฟล์ CSV ทั้งหมดเป็น UTF-8 with BOM ขึ้นบรรทัดใหม่แบบ CRLF ดับเบิลคลิกใน Excel แล้วแสดงอักษรจีน ญี่ปุ่น เกาหลี และไทยได้ถูกต้อง ไฟล์คำอธิบายนี้เป็น UTF-8 (ไม่มี BOM)
- **ข้อจำกัดที่ทราบ**:
  - `04_story_title`, `06_location` และ `09_scenario_character` สร้างจากเนื้อเรื่องและข้อมูลชุมชน และจะเติมภาษาอื่นให้อัตโนมัติเฉพาะเมื่อ**รูปแบบเขียนตรงกันทุกตัวอักษร**กับตารางทางการเท่านั้น จึงไม่ใช่ทุกคำที่จะครบทั้ง 6 ภาษา (โฟลเดอร์นี้มี `06_location` เพียง 8 คำ และ `08_event` เพียง 45 คำ ขณะที่จีนตัวย่อ / ญี่ปุ่นครอบคลุม 90 และ 72 คำ)
  - หมวดตัวละครมีรายการ「ชื่อเต็ม」(นามสกุล + ชื่อ) เพิ่มเติม แต่มีเฉพาะสามภาษาจีน ญี่ปุ่น เกาหลีเท่านั้น เพราะภาษาอังกฤษและภาษาไทยเรียงลำดับชื่อตรงข้ามกับจีน ญี่ปุ่น เกาหลี และข้อมูลทางการไม่มีรูปแบบที่นำมาต่อกันได้โดยตรง (โฟลเดอร์นี้จึงมี `01_character` 204 คำ)
  - คำที่รูปแบบเขียนเหมือนกับภาษาปลายทางทุกตัวอักษรจะไม่ถูกบันทึกในคลังศัพท์ และเมื่อชื่อเดียวมีข้อมูลหลายรายการ (เช่น ศัตรูชื่อเดียวกันแต่ต่างระดับ) จะถูกรวมเป็นคำเดียว
  - คำจำนวนน้อยมาก (ประมาณ 1%–3%) จะมี `source` หนึ่งคำจับคู่กับ `target` หลายค่า**ภายในไฟล์ภาษาปลายทางเดียวกัน** ส่วนใหญ่มาจากคำสั้นที่เป็นของต่างสิ่งแต่ชื่อซ้ำ (เช่น `Normal` เป็นทั้งประเภทเกราะและระดับความหายากของไอเทม) เครื่องมือที่ตัดคำซ้ำด้วย `source` จะเก็บไว้เพียงรายการเดียว หากต้องแยกแยะโปรดใช้ `id` และ `src_table` ใน `_terms.csv` เพื่อตรวจบริบท

## ข้อจำกัดความรับผิด

โฟลเดอร์นี้เป็นคลังศัพท์คำแปลภาษาไทย**ที่ไม่เป็นทางการ** จัดทำและดูแลโดยบุคคลคนเดียว ใช้เพื่อการศึกษาส่วนบุคคล การวิจัย และช่วยจับคู่ศัพท์ในซอฟต์แวร์แปลด้วย AI (รวมถึงแต่ไม่จำกัดเพียง Immersive Translate) เท่านั้น คลังนี้ไม่มีความเกี่ยวข้องด้านสังกัด การอนุญาต ความร่วมมือ ตัวแทน หรือการเป็นผู้แทนอย่างเป็นทางการใด ๆ กับ『บลูอาร์ไคฟ์』และผู้พัฒนา ผู้จัดจำหน่าย ตัวแทนจำหน่าย หรือผู้ถือสิทธิ์ คำแปลในคลังไม่ใช่จุดยืนอย่างเป็นทางการ ไม่รับประกันว่าจะถูกต้อง ครบถ้วน หรือสอดคล้องกับเวอร์ชันปัจจุบันของเกมเสมอ และ**ไม่ควรถือเป็นคลังศัพท์อย่างเป็นทางการหรือไฟล์โลคัลไลเซชันอย่างเป็นทางการของเกมใด ๆ** ชื่อเกม ชื่อตัวละคร คำเฉพาะ เครื่องหมายการค้า และทรัพย์สินทางปัญญาอื่น ๆ เป็นของผู้ถือสิทธิ์แต่ละราย คลังนี้ไม่เรียกร้องสิทธิ์ใด ๆ เหนือทรัพย์สินทางปัญญาของบุคคลที่สามดังกล่าว ความรับผิดชอบทั้งหมดที่เกิดจากการใช้โครงการนี้และผลลัพธ์การแปลที่สร้างจากโครงการนี้เป็นของผู้ใช้เอง หากผู้ถือสิทธิ์เห็นว่าเนื้อหาไม่เหมาะสม ยินดีรับการติดต่อผ่าน GitHub Issues / Pull Request ผู้ดูแลจะตรวจสอบแล้วแก้ไขหรือลบออก ข้อกำหนดฉบับเต็มอยู่ใน `README.md` / `README_EN.md` / `README_JP.md` ที่รากของรีโพซิทอรี
