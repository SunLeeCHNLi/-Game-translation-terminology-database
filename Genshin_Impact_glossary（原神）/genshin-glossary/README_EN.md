# Genshin Impact Multilingual Terminology Database

## [中文](README.md) [日本語](README_JP.md)

Split into separate folders by **target language**, with files stored by **category** inside each folder.

## Data Sources

- Main glossary: [theBowja/genshin-db](https://github.com/theBowja/genshin-db) (data version 7.0, covering all 14 languages)
- Supplementary glossary: see the sibling directory `genshin-glossary-supplement/` (source [xicri/genshin-langdata](https://github.com/xicri/genshin-langdata), covering zh-CN / zh-TW / en-US / ja-JP)

> is stored in the sibling `tools/glossary_counts.json`, not inside this directory.

## File Format

All CSVs are **UTF-8 (with BOM)** encoded, **CRLF** line endings, with a header row, and fields containing commas or quotation marks are escaped with quotes per RFC 4180.

| source | target | tgt_lng |
| --- | --- | --- |
| Alhacén | 艾尔海森 | zh-CN |
| Alhaitham | 艾尔海森 | zh-CN |

Meaning: for the target language specified by `tgt_lng`, `target` is the translation and `source` is the original text in **any of the other languages**.
That is, inside each language folder, the same entry appears as one row for each of the other 13 languages as `source` (duplicate rows and identical-form rows have been merged).

## Data Cleaning Notes

The following markers in the source data have already been handled at generation time:

| Source notation | Handling | Example |
| --- | --- | --- |
| Adjacent gender variants in `{M#...}{F#...}` | Take the male form | `{M#du débutant}{F#de la débutante}` → `du débutant` |
| Standalone `{M#…}` / `{F#…}` | Take their content | `#Искатель{F#ница}` → `Искательница` |
| Leading `#` in a name (gender-related marker) | Remove | `#Éclaireuse 100%` → `Éclaireuse 100%` |
| `{NON_BREAK_SPACE}`, `{SPACE}` | Replace with an ordinary space | `PB{NON_BREAK_SPACE}-{NON_BREAK_SPACE}Retorno` → `PB - Retorno` |
| Other placeholders (kept as is) | `{NICKNAME}`, `{REALNAME[…]} `, `{MATEAVATAR#SEXPRO[…]} ` | 1 row each |

Duplicate rows with the same name and the same translation (for example, personal names written identically in English/French/German) have been merged.

## Usage Tips

- When importing into CAT tools (Trados, memoQ, Phrase, etc.), simply choose the CSV of the corresponding target language and import it directly as a terminology base.
- The file name is the category name, and they can be merged as needed; if you need "all categories merged into a single file" or an added `src_lng` (source language) column, it can be generated at any time.

## Generation Notes

This directory is generated by the sibling `tools/build_main_glossary.js` from the [genshin-db](https://github.com/theBowja/genshin-db) source:

```bash
node tools/build_main_glossary.js
```

The script writes all 14 language folders, 27 CSVs, and the statistic metadata `glossary_counts.json` into the output directory;
the copy of the statistic metadata kept in the repository is located at `tools/glossary_counts.json`. The tables in this README are generated by `tools/readme_main.js`.
