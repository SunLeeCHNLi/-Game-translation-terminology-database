# Genshin Impact Multilingual Terminology Database - Supplement

## [简体中文](README.md) [日本語](README_JP.md)

This directory is a **supplement** to `genshin-glossary/`, used to fill in entries that the main glossary does not contain (especially NPCs, place names, enemies, quests, and so on).

## Data Sources

- [xicri/genshin-langdata](https://github.com/xicri/genshin-langdata) (covering the four languages en / ja / zh-CN / zh-TW)

## Relationship to the Main Glossary

- It contains only `source/target/tgt_lng` combinations that are **not already in the main glossary**, so it can be **stacked directly on top of** the main glossary without producing duplicate entries.
- It covers only 4 target languages: `zh-CN`, `zh-TW`, `en-US`, `ja-JP`.
- Because the sources differ, the English/Japanese/Chinese rendering of the same entry may differ slightly from the main glossary (for example in wording or punctuation).

## Directory Structure

```
genshin-glossary-supplement/
├── zh-CN/
│   ├── characters.csv        # Main categories that share their names with the main glossary
│   ├── _variants.csv         # Aliases / colloquial names / common misspellings, added as extra sources
│   └── extra/                # Additional categories beyond the main ones, commonly used in Genshin translation
│       ├── quests.csv
│       └── ...
├── zh-TW/  en-US/  ja-JP/
└── (build metadata has been moved to ../tools/supplement_counts.json at the same level)
```

> This directory is generated by `tools/build_supplement.mjs` at the same level; the build metadata (row counts
> per language and per category) is stored in `tools/supplement_counts.json` at the same level and is not inside this directory.

## File Format

Exactly the same as the main glossary (UTF-8 with BOM, CRLF, RFC 4180 escaping):

| source | target | tgt_lng |
| --- | --- | --- |
| Blackmarrow Lantern | 鸟髄孑灯 | zh-CN |
| 鳥髄の狐灯 | 鸟髄孑灯 | zh-CN |

## Build Notes

This directory is generated by `tools/build_supplement.mjs` at the same level, which reads two inputs: the dataset
from `xicri/genshin-langdata`, and **all the CSVs already generated by the main glossary `genshin-glossary/`** (used to remove duplicate rows):

```bash
node tools/build_main_glossary.js   # generate the main glossary first
node tools/build_supplement.mjs     # then generate the supplement glossary (depends on the previous step's output)
```

The script writes the 4 language folders and the statistics metadata `supplement_counts.json` into the output directory;
the copy of that statistics metadata kept in the repository is located at `tools/supplement_counts.json`. The tables in this README are generated by `tools/readme_sup.js`.
