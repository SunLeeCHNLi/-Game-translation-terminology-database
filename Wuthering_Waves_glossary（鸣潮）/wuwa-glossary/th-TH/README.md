# Wuthering Waves（鸣潮）คลังคำศัพท์ — ภาษาไทย（`th-TH`）

[← กลับไปยังคำอธิบายภาพรวมของเกม](../../README.md) ｜ [← คำอธิบายคลังย่อย wuwa-glossary](../README.md)

ไดเรกทอรีนี้เป็นคลังคำศัพท์ของ Wuthering Waves **โดยใช้ `th-TH` (ภาษาไทย) เป็นภาษาเป้าหมาย** มี **123,230** คำศัพท์ และ **644,759** แถวเทียบเคียง (ผลรวมแถวข้อมูลของไฟล์ CSV 23 ไฟล์ในไดเรกทอรีนี้ ประมาณ **91.4 MiB**) คอลัมน์ `tgt_lng` ของทุกไฟล์ CSV ถูกกำหนดเป็น `th-TH` คงที่ และคอลัมน์ `source` เก็บรูปแบบของอีก 9 ภาษา (`zh-CN` (简体中文), `zh-TW` (繁體中文), `en-US` (English), `ja-JP` (日本語), `ko-KR` (한국어), `fr-FR` (Français), `de-DE` (Deutsch), `es-ES` (Español), `pt-BR` (Português)) จึงเทียบข้อความในเกมข้อความเดียวกันกับคำแปลในภาษานี้ได้จากทุกภาษา

## ไฟล์

ไดเรกทอรีนี้เป็น**โครงสร้างแบบแบน** ไฟล์ CSV ทั้ง 23 หมวดอยู่ในไดเรกทอรีนี้โดยตรง ไม่มีไดเรกทอรีย่อยเพิ่มเติม:

- `npcs.csv` — NPC และผู้พูด
- `achievements.csv` — ความสำเร็จ

ทุกไฟล์มีสามคอลัมน์ `source,target,tgt_lng` (แถวแรกเป็นหัวตาราง) สำหรับภาษาเป้าหมายที่ระบุใน `tgt_lng` นั้น `target` คือคำแปล และ `source` คือต้นฉบับใน**ภาษาอื่นภาษาหนึ่ง** ดังนั้นหนึ่งรายการจะปรากฏหนึ่งแถวต่อหนึ่งภาษาอื่นที่เหลือ (แถวซ้ำและแถวที่เขียนเหมือนกันถูกยุบรวมแล้ว จำนวนแถวจึงไม่ใช่เก้าเท่าของจำนวนคำศัพท์) ไฟล์เหล่านี้สามารถนำเข้าเครื่องมือ CAT หรือซอฟต์แวร์จับคู่คำศัพท์อย่าง Immersive Translate ได้โดยตรง

“จำนวนคำศัพท์” คือจำนวนคำศัพท์หลังตัดรายการซ้ำ (หนึ่งคำศัพท์ = หนึ่งคีย์ข้อความในเกม) มาจากฟิลด์ `concepts` ใน `tools/_counts.json` ซึ่ง**ใช้ร่วมกันทั้งฐานข้อมูลและไม่ขึ้นกับภาษาเป้าหมาย** ส่วน “แถวเทียบเคียง” คือจำนวนแถวข้อมูลจริงของไฟล์ CSV หมวดนั้นในไดเรกทอรีนี้ ข้อความเดียวกันอาจอยู่หลายหมวด ผลรวมแถวของแต่ละหมวดจึงมากกว่าจำนวนคำศัพท์หลังตัดรายการซ้ำ ซึ่งเป็นเรื่องปกติ

## หมายเหตุ

- **ที่มาของคำแปล**: คอลัมน์ `target` คัดลอกมาจากไฟล์โลคัลไลซ์ของตัวเกมโดยตรง ([Arikatsu/WutheringWaves_Data](https://github.com/Arikatsu/WutheringWaves_Data) ไฟล์ `Textmaps/<lang>/multi_text/MultiText.json` เกมเวอร์ชัน 3.6.0 และเติมคีย์บางส่วนจาก [Dimbreath/WutheringData](https://github.com/Dimbreath/WutheringData) ไฟล์ `TextMap/<lang>/MultiText.json` เกมเวอร์ชัน 3.1.0) เป็นคำศัพท์ทางการที่ใช้ในเกม ไม่ใช่การแปลต่อ
- **การจับคู่**: จับคู่ด้วยคีย์ข้อความของเกม (เช่น `RoleInfo_1402_Name`) ข้อความของคีย์เดียวกันในภาษาอื่นจะกลายเป็นแถว `source` ของ `target` ในไดเรกทอรีนี้
- **แท็กภาษา**: `tgt_lng` ถูกกำหนดเป็นรหัสภาษาของไดเรกทอรีนี้ และตรงกับชื่อไดเรกทอรี
- **การเข้ารหัส**: ไฟล์ CSV ทุกไฟล์เป็น **UTF-8 (มี BOM)** ขึ้นบรรทัดใหม่แบบ **CRLF** และมีแถวหัวตาราง ฟิลด์ที่มีจุลภาคหรือเครื่องหมายอัญประกาศจะถูก escape ตาม RFC 4180 จึงเปิดใน Excel ได้ทันที
- **ข้อจำกัดที่ทราบ**: ค่าเริ่มต้นไม่รวมบทสนทนาเนื้อเรื่องแบบรายบรรทัด (ประมาณ 170,000 แถวต่อภาษา) หากต้องการสามารถสร้างเพิ่มได้ด้วยออปชัน `--with-dialogue` วิธีทำดูได้จาก `../README.md` ข้อความที่ยาวเกินจะถูกตัดตามหมวดหมู่ด้วย `MAX_LEN` ใน `tools/wuwa_config.py` ภาษา `ru-RU`, `id-ID` และ `vi-VN` เป็นไฟล์ว่างในต้นทางจึงไม่มีในคลังนี้ ส่วน `it-IT` และ `tr-TR` ไม่ใช่ภาษาข้อความที่เกมรองรับ

## ข้อจำกัดความรับผิด

ไดเรกทอรีนี้เป็นคลังคำศัพท์แปลแบบ**ไม่เป็นทางการ**ที่จัดทำและดูแลโดยบุคคลคนเดียว ใช้เพื่อการเรียน การศึกษา และช่วยจับคู่คำศัพท์ของซอฟต์แวร์แปลด้วย AI (รวมถึงแต่ไม่จำกัดเพียง Immersive Translate) เท่านั้น คลังนี้ไม่มีความสัมพันธ์ใด ๆ ในลักษณะสังกัด อนุญาต ร่วมมือ เป็นตัวแทน หรือเป็นตัวแทนอย่างเป็นทางการ กับผู้พัฒนา ผู้จัดจำหน่าย ผู้ให้บริการ หรือผู้ถือสิทธิ์ของเกมที่เกี่ยวข้อง คำแปลที่ปรากฏไม่ถือเป็นจุดยืนอย่างเป็นทางการ ไม่รับประกันว่าถูกต้อง ครบถ้วน หรือตรงกับเวอร์ชันปัจจุบันของเกม และ**ไม่ควรถือเป็นคลังคำศัพท์อย่างเป็นทางการหรือไฟล์โลคัลไลซ์อย่างเป็นทางการของเกมใด ๆ** ชื่อเกม ชื่อตัวละคร คำเฉพาะ เครื่องหมายการค้า และทรัพย์สินทางปัญญาอื่น ๆ เป็นของเจ้าของสิทธิ์แต่ละราย โครงการนี้ไม่กล่าวอ้างสิทธิ์ใด ๆ เหนือสิ่งเหล่านั้น หากเจ้าของสิทธิ์เห็นว่าเนื้อหาไม่เหมาะสม โปรดติดต่อผ่าน GitHub Issues / Pull Request ทางผู้ดูแลจะตรวจสอบแล้วแก้ไขหรือลบออก ข้อกำหนดฉบับเต็มอยู่ใน `README.md` / `README_EN.md` / `README_JP.md` ที่รากของรีโป
