# 鳴潮 用語集 / Wuthering Waves Terminology Database / 《鸣潮》翻译术语库

## [中文](README.md) [English](README_EN.md)

本ライブラリは、オープンワールドアクションRPG『**鳴潮**』（Wuthering Waves）の固有名詞対訳表です。キャラクター名、武器、音骸（エコー）、スキル、共鳴チェーン、クエスト、ダンジョン、地域、陣営、アイテム、モンスター、NPC、実績、イベント、バフ、ボイス、アーカイブ、用語、システムテキスト、UIテキスト、チュートリアル、ストーリーテキスト、その他の計 **23 分類**を収録しています。全分類の合計は **123,230** 項目で、対象言語ごとに **10 種類**の独立した用語集（`zh-CN` / `zh-TW` / `en-US` / `ja-JP` / `ko-KR` / `fr-FR` / `de-DE` / `es-ES` / `pt-BR` / `th-TH`）に分割され、合計 **230 個の CSV / 6,480,146 行の対訳**（約 638.6 MiB）になります。訳語はすべて公式クライアントの多言語テキストから取得し、同一のテキストキーで対応付けているため、**公式ローカライズ**であり二次翻訳ではありません。

## 使用方法

1. **単一ファイルのダウンロード**：`wuwa-glossary/` 配下の目的の言語ディレクトリ（例：`zh-CN/`）を開き、必要な分類ファイル（`characters.csv`、`items.csv` など）をダウンロードします。没入型翻訳、Trados、memoQ、Phrase などの用語ツールにそのままインポートでき、変換は不要です。
2. **言語ディレクトリごとの一括ダウンロード**：ある言語の全分類が必要な場合は、その言語ディレクトリ内の 23 個の CSV（約 55〜92 MiB）をダウンロードします。
3. **リポジトリ全体をクローンして再生成**：`git clone` の後、`tools/` に収録されている生成スクリプトと、そのスクリプトが参照する 2 つの上流データリポジトリ（`WutheringWaves_Data`、`WutheringData`）のソースを使えば、元データから全 CSV を再生成できます。

> ファイル名がそのまま分類名です。必要に応じて統合して使用できます。領域ごとに分割してインポートする（例：`characters.csv` + `weapons.csv` + `skills.csv` のみ）と、用語のマッチ精度が大きく向上します。

## ディレクトリ構成

```text
Wuthering_Waves_glossary（鸣潮）/
  README.md                中国語の説明
  README_EN.md             英語の説明
  README_JP.md             日本語の説明（本ファイル）
  wuwa-glossary/           用語集データ（対象言語ごとに 10 套）
    README.md              サブライブラリの詳細（分類表、クリーニング規則、再生成コマンド）
    zh-CN/                 対象言語＝簡体字中国語、23 分類の CSV
    zh-TW/                 対象言語＝繁体字中国語
    en-US/                 対象言語＝英語
    ja-JP/                 対象言語＝日本語
    ko-KR/                 対象言語＝韓国語
    fr-FR/                 対象言語＝フランス語
    de-DE/                 対象言語＝ドイツ語
    es-ES/                 対象言語＝スペイン語
    pt-BR/                 対象言語＝ポルトガル語
    th-TH/                 対象言語＝タイ語
  tools/                   バッチスクリプトと生成メタデータ
    build_wuwa_glossary.py メイン生成スクリプト（テキストキー → 分類 CSV）
    wuwa_classify.py       テキストキーを分類へ割り当て
    wuwa_config.py         分類の閾値とパラメータ設定
    _counts.json           言語別・分類別の項目数とサイズの統計
```

各言語ディレクトリの構成は完全に同一で、いずれも **23 個の分類 CSV** のみ（サブディレクトリなし）です。また各言語ディレクトリには `README.md`（その言語）と `README_zh-CN.md`（簡体字中国語）の 2 つの説明ファイルがあります。

### ファイル形式

各分類 CSV は 3 列で、**UTF-8（BOM 付き）**、**CRLF** 改行、カンマ・引用符・改行を含むフィールドは RFC 4180 に従って引用符でエスケープしています（Excel でダブルクリックしてそのまま開けます）。

| source | target | tgt_lng |
| --- | --- | --- |
| Yangyang | 秧秧 | zh-CN |
| 秧秧（ヤンヤン） | 秧秧 | zh-CN |

- `target`：そのディレクトリの対象言語による訳語
- `tgt_lng`：対象言語タグ（ディレクトリ名と同一）
- `source`：同一テキストキーの**残り 9 言語**での表記。したがって 1 項目は原語ごとに 1 行ずつ現れます（重複行と同形行は統合済み）

### 収録していない言語

`ru-RU`（ロシア語）、`id-ID`（インドネシア語）、`vi-VN`（ベトナム語）は、上流の 2 つのデータリポジトリにおいて**空のプレースホルダファイル**です（3.6.0 と 3.1.0 のいずれも同じ）。そのため提供できません。`it-IT`、`tr-TR` は鳴潮が公式にサポートするテキスト言語ではありません。上流が今後整備すれば、生成コマンドを再実行するだけで自動的に取り込まれます。

## 再生成

先に 2 つの上流データリポジトリを `E:\Download\BT\Codex_input` に配置するか、環境変数 `WUWA_DATA_ROOT` で別の場所を指定してください。

```bash
# 全量生成（既定。wuwa-glossary/ へ出力）
python tools/build_wuwa_glossary.py --out ./wuwa-glossary

# 一部の分類のみ生成（サイズが小さく、マッチ精度が高い）
python tools/build_wuwa_glossary.py --out ./wuwa-glossary --only characters,weapons,echoes,skills,resonant-chains

# 長文の閾値を圧縮（短い用語のみ残す場合など。サイズは約 1/3）
python tools/build_wuwa_glossary.py --out ./wuwa-glossary --len-scale 0.5

# 逐句のストーリー台詞 dialogue.csv も生成（非常に大きく、言語あたり約 +170 MiB。既定では生成しない）
python tools/build_wuwa_glossary.py --out ./wuwa-glossary --with-dialogue
```

その他の引数：`--dry-run`（集計のみで書き込みなし）、`--rebuild-cache`（`BinData`/`ConfigDB` を再スキャン。既定では結果を `tools/_cfgmap_cache.pkl` にキャッシュ）。

生成時には統計メタデータ `_counts.json` が出力されます。本リポジトリに保存されているものは `tools/_counts.json` です。

## 説明

### テキストクリーニング

元データの以下の内容は生成時に処理済みです。

| 元データの表記 | 処理 | 例 |
| --- | --- | --- |
| `<color=...>`、`<size=...>`、`<i>`、`<b>` などのリッチテキストタグ | タグを除去 | `<color=Highlight>共鸣解放</color>` → `共鸣解放` |
| `{Male=…;Female=…}` の性別分岐 | 男性形を採用 | `{Male=大哥哥;Female=大姐姐}` → `大哥哥` |
| `{M#…}{F#…}` の性別変異 | 男性形を採用 | `{M#du débutant}{F#de la débutante}` → `du débutant` |
| リテラルの `\n` | 改行に復元 | `第一行\n第二行` → 2 行 |
| `dnt/` 接頭辞（do not translate） | 接頭辞を除去 | `dnt/测试` → `测试` |
| 原文と訳文が完全に同一の行 | 出力しない | — |

### 収録範囲

- **既定では逐句のストーリー台詞を収録しません**（話者台詞・字幕、言語あたり約 170,000 件）。収録すると 1 言語あたり約 60 MiB から約 230 MiB に増えます。
- 長すぎるテキストは分類ごとの閾値で切り詰めます。閾値は `tools/wuwa_config.py` の `MAX_LEN` で定義しています（例：`ui` 60 文字、`story` 200 文字、`items` 250 文字、`archives` 400 文字）。
- テキストキーから分類への割り当ては、ゲーム設定テーブルのフィールド参照に基づきます。どの設定テーブルからも参照されない少数のキーは、命名規則によるフォールバックで分類します。

### 既知の制限

- 分類は設定テーブルのフィールドから自動的に割り当てるため、一部の項目が隣接する分類に入ることがあります。
- 収録範囲は上流データリポジトリのバージョン（3.6.0 / 3.1.0）に依存します。ゲームの更新後は再生成が必要です。
- 地域版によって訳名が異なる場合があります。本ライブラリは参照した上流データのバージョンに従います。
