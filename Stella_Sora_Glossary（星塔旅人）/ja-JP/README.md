# Stella Sora 用語集 — 日本語（`ja-JP`）

[← ゲーム全体の説明に戻る](../README.md)

本ディレクトリは**対象言語を `ja-JP`（日本語）とする用語集**です。各行は「他言語での表記 → 日本語」の対照で、合計 **12289** 件の用語と **46426** 行の対照行を収録しています。`tgt_lng` 列は常に `ja-JP` で、`source` 列には `zh-CN` / `zh-TW` / `en-US` / `ko-KR` の 4 言語における同一用語の表記が入ります。各用語を 5 言語並列で確認したい場合は `00_master/README.md` と `../multilingual/00_master/` を参照してください。

## ファイル

- `NN_xxx/NN_xxx_glossary.csv` — `source,target,tgt_lng` の 3 列。CAT / 用語管理ツールへ直接インポートできます
- `NN_xxx/NN_xxx_terms.csv` — 本言語の用語一覧（`id,term,src_table`）。校正や照会に適しています
- `00_master/all_glossary.csv` — 15 分類すべての対照行を統合した表（`category,source,target,tgt_lng`）
- `00_master/all_terms.csv` — 本言語の全用語一覧（`category,category_label,id,term,src_table`）
- `00_master/index.csv` — 分類索引と件数（`category,label,term_count,glossary_file,terms_file,target_language`）
- `00_master/README.md` — 本言語の既存の詳細説明

`NN_xxx/` は 15 の分類ディレクトリで、各ディレクトリには上記 2 ファイルだけが入っています。`terms.csv` の 1 データ行が 1 用語、`glossary.csv` の各行が 1 つの `source → target` 対照です。

## 説明

- **訳文の出典と対応付け**：訳文はすべてゲーム公式の多言語テキストライブラリ `StellaSoraData-main`（公式の CN / EN / JP / KR / TW クライアントテキスト）に由来し、各言語は同一のテキストキーで対応付けられています。**公式ローカライズ**であり二次翻訳ではありません。各用語は残り 4 言語の表記を対照行として展開するため、本ディレクトリは「日本語 → 他言語」の逆引きにも使えます。
- **言語タグ**：本データベースで使用する 5 つのタグは `zh-CN` 簡体字中国語、`zh-TW` 繁體中文、`en-US` English、`ja-JP` 日本語、`ko-KR` 한국어 です。本ディレクトリの `tgt_lng` は常に `ja-JP` です。
- **文字コード**：すべての CSV は UTF-8 with BOM、CRLF 改行です。Excel でダブルクリックすれば中日韓文字が正しく表示されます。本説明ファイルは UTF-8（BOM なし）です。
- **対照行が「件数 × 4」より少ない理由**：分割スクリプトは、対象言語の表記と完全に同じ `source`、および同一分類内で既に出現した `source` → `target` 対照行を削除します（`06_equipment` が 15 件の用語に対して 58 行なのはこのためです）。
- **既知の制限**：
  - セリフ、ストーリー本文、アイテム説明などの長文は本用語集の対象外です；
  - `14_location` のうち `DatingLandmark` と `StarTower` 以外の地名は人手で校訂して補い、出典を `curated (aligned in-game text)` と表記しています；
  - `06_equipment` は 15 件のみです。本作には従来型の武器 / 防具表がなく、装備枠は「秘紋（Disc）」が担っています；
  - 本ディレクトリには 1 つの `source` が複数の `target` に対応する例が 1269 件あります。多くは同名異物の短い語に由来します（例：簡体字 `薇洛` が「ウィロー」と「ウィロー（水着）」の両方に対応）。`source` で重複除去するツールは 1 件しか残しません。区別が必要な場合は `terms.csv` の `id` と `src_table` で文脈を確認してください；
  - 本ディレクトリは 12289 件で、`zh-CN` より 3 件少なくなっています。差異はすべて `11_ui` にあり、公式 UI テキストの一部の項目が日本語リージョンに独立した訳文を持たないためです。
- **再生成**：本ディレクトリは `tools/split_by_language.py` が `multilingual/` を分割して生成したものです。スクリプトは固定の外部絶対パス（`E:\Download\BT\Codex_input\StellaSora_Glossary`）を使用し、**本リポジトリの読み書きは行いません**。詳細はゲーム直下の `README.md` の「再生成」を参照してください。
