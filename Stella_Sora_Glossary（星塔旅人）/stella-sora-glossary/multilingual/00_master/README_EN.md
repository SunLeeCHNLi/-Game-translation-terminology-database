# Stella Sora Five-Language Side-by-Side Master Table (`multilingual/`)

## [简体中文](README.md) [日本語](README_JP.md)

Generated by aligning key by key the local game multilingual text database `StellaSoraData-main` (official CN / EN / JP / KR / TW region texts).
Every term has exactly the same ID in all five languages, so they are official translations of one another and have not been retranslated by hand.

This directory (`Stella_Sora_Glossary（星塔旅人）/multilingual/`) is the **raw five-language side-by-side master table**, not a single-target-language termbase,
and therefore has no language-level `README.md` / `README_zh-CN.md`; the splits targeting a single language are in the game root's
`zh-CN/`, `zh-TW/`, `en-US/`, `ja-JP/` and `ko-KR/` directories. For the game-level overview see the game root's
`README.md` / `README_EN.md` / `README_JP.md`.

## Totals

- Total terms: **12292** (the term count is identical in all five languages; the only differences appear in the `11_ui` category of the single-language directories)
- Languages: `zh-CN` (Simplified Chinese), `en-US` (English), `ja-JP` (Japanese), `ko-KR` (Korean), `zh-TW` (Traditional Chinese) — all five languages are included
- Categories: 15 dedicated glossaries
- Alignment rows: the `NN_xxx_glossary.csv` of the 15 categories total **147462** rows (at most 12 rows per term)
- Generation date: 2026-09-11

## File Format

Each category folder contains two files:

**1. `NN_xxx_terms.csv` — multilingual side-by-side master table**

| id | zh-CN | en-US | ja-JP | ko-KR | zh-TW | src_table |
| --- | --- | --- | --- | --- | --- | --- |
| Character.103.1 | 琥珀 | Amber | コハク | 코하쿠 | 琥珀 | Character.json |

- `id`: the original in-game text key, usable for lookups, comparison and automated updates
- `src_table`: which data table the term was taken from
- One term per row, five languages side by side; the row count of `terms.csv` is that category's term count (the 15 categories total 12292 rows, matching the 12292 rows of `StellaSora_all_terms.csv`)

**2. `NN_xxx_glossary.csv` — glossary (source / target / tgt_lng)**

Exported in the requested table format, with the four languages paired in every ordered combination, ready to import into CAT / terminology management tools:

| source | target | tgt_lng |
| --- | --- | --- |
| Amber | 琥珀 | zh-CN |
| 琥珀 | Amber | en-US |
| Amber | コハク | ja-JP |
| 코하쿠 | 琥珀 | zh-CN |

Each term expands into at most 12 rows (the 4×3 ordered language pairs of the four languages zh-CN / en-US / ja-JP / ko-KR),
so it can be searched directly whichever language is used as the source. All files are UTF-8 with BOM, CRLF line endings,
and Excel displays CJK text correctly on a double-click.

> Not every term reaches a full 12 rows: language pairs missing a translation on one side are skipped, and the 15 categories total 147462 rows
> (the full value would be 12292 × 12 = 147504; the shortfall of 42 rows all comes from `11_ui`, where a small number of UI texts have no separate translation in some regions).

## Extraction and Filtering Rules

- Only “name / label” fields are extracted (usually `.1`; the disc tables use `.1/.2/.3`); descriptions, numeric values, dialogue bodies and other long text are **not** included;
- `Item.json` is routed precisely into items, potentials, discs, emblems, avatars and other categories according to the `Type`/`Stype` columns of the config table;
- Interface texts (UIText and friends) keep only short terms (Simplified Chinese ≤24 characters and without sentence-ending punctuation), filtering out full-sentence prompts;
- Entries whose five-language content is completely identical within the same category are merged into one (keeping the source-table ID of the first occurrence);
- Placeholders and deprecated entries such as `【不要翻译】`, `【废弃】` and `[no trans]` have been removed;
- Rich-text markup such as `<color=…>` and `<sprite …>` has been stripped.

## Generation and Reproduction

```bash
# Generate this directory (the five-language side-by-side master table). The script uses hard-coded external absolute paths:
#   input  E:\Download\BT\Codex_input\StellaSoraData-main\StellaSoraData-main
#   output E:\Download\BT\Codex_input\StellaSora_Glossary
python tools/build_glossary.py

# Split this directory into single-language termbases. The script likewise uses the external absolute path
# E:\Download\BT\Codex_input\StellaSora_Glossary and writes _summary.json to that external root
python tools/split_by_language.py
```

Both scripts are under the game root's `tools/`, and **neither of them reads or writes this repository**: the contents of this directory are a snapshot copied in after the external generation pipeline has finished.

## Known Limitations

- Long-form content such as dialogue, story bodies and item descriptions is outside the scope of this termbase; export it separately as a translation memory (TMX / bilingual alignment) if needed;
- Apart from `DatingLandmark` and `StarTower`, the place names in `14_location` have no dedicated table in the game data,
  so they have been manually curated and added from officially aligned texts such as character archive addresses, achievements and story titles, and are marked with the source `curated (aligned in-game text)`;
- `06_equipment` has only 15 entries: this game has no traditional weapon/armour table, and the equipment slot is taken by the “Disc”.
