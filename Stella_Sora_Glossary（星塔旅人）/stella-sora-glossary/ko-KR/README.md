# Stella Sora 용어집 — 한국어 (`ko-KR`)

[← 게임 전체 설명으로 돌아가기](../README.md)

이 디렉터리는 **대상 언어를 `ko-KR`(한국어)로 하는 용어집**입니다. 각 행은 「다른 언어 표기 → 한국어」 대응이며, 총 **12292**개 용어와 **45950**행의 대응 행을 수록하고 있습니다. `tgt_lng` 열은 항상 `ko-KR`이고, `source` 열에는 `zh-CN` / `zh-TW` / `en-US` / `ja-JP` 4개 언어에서 같은 용어의 표기가 들어갑니다. 각 용어를 5개 언어 병렬로 확인하려면 `00_master/README.md`와 `../multilingual/00_master/`를 참고하십시오.

## 파일

- `NN_xxx/NN_xxx_glossary.csv` — `source,target,tgt_lng` 3개 열. CAT / 용어 관리 도구에 바로 가져올 수 있습니다
- `NN_xxx/NN_xxx_terms.csv` — 이 언어의 용어 목록(`id,term,src_table`). 교정과 조회에 적합합니다
- `00_master/all_glossary.csv` — 15개 분류의 대응 행을 모두 합친 표(`category,source,target,tgt_lng`)
- `00_master/all_terms.csv` — 이 언어의 전체 용어 목록(`category,category_label,id,term,src_table`)
- `00_master/index.csv` — 분류 색인과 개수(`category,label,term_count,glossary_file,terms_file,target_language`)
- `00_master/README.md` — 이 언어의 기존 상세 설명

`NN_xxx/`는 15개 분류 디렉터리이며, 각 디렉터리에는 위 두 파일만 들어 있습니다. `terms.csv`의 데이터 행 하나가 용어 하나이고, `glossary.csv`의 각 행은 `source → target` 대응 하나입니다.

## 설명

- **번역 출처와 정렬 방식**: 번역은 모두 게임 공식 다국어 텍스트 라이브러리 `StellaSoraData-main`(공식 CN / EN / JP / KR / TW 클라이언트 텍스트)에서 가져왔고, 각 언어는 동일한 텍스트 키로 정렬되어 있습니다. 따라서 **공식 현지화**이며 2차 번역이 아닙니다. 각 용어는 나머지 4개 언어의 표기를 대응 행으로 펼치므로, 이 디렉터리는 「한국어 → 다른 언어」 역방향 조회에도 쓸 수 있습니다.
- **언어 태그**: 이 데이터베이스에서 쓰는 5개 태그는 `zh-CN` 중국어 간체, `zh-TW` 중국어 번체, `en-US` English, `ja-JP` 日本語, `ko-KR` 한국어입니다. 이 디렉터리의 `tgt_lng`는 항상 `ko-KR`입니다.
- **인코딩**: 모든 CSV는 UTF-8 with BOM, CRLF 줄바꿈입니다. Excel에서 두 번 클릭하면 한중일 문자가 올바르게 표시됩니다. 이 설명 파일은 UTF-8(BOM 없음)입니다.
- **대응 행이 「용어 수 × 4」보다 적은 이유**: 분할 스크립트가 대상 언어 표기와 완전히 같은 `source`, 그리고 같은 분류 안에서 이미 나온 `source` → `target` 대응 행을 제거하기 때문입니다(`06_equipment`가 용어 15개에 대응 행 58개인 것이 이 때문입니다).
- **알려진 한계**:
  - 대사, 스토리 본문, 아이템 설명 같은 장문은 이 용어집의 범위가 아닙니다;
  - `14_location` 가운데 `DatingLandmark`와 `StarTower`를 제외한 지명은 사람이 교정해 보충했으며, 출처를 `curated (aligned in-game text)`로 표기했습니다;
  - `06_equipment`는 15개뿐입니다. 이 게임에는 전통적인 무기 / 방어구 표가 없고, 장비 칸은 「비문(Disc)」이 담당합니다;
  - 이 디렉터리에는 하나의 `source`가 여러 `target`에 대응하는 사례가 700개 있습니다. 대부분 같은 이름의 다른 대상에서 비롯됩니다(예: 영어 `Amber`가 「노란빛」과 「코하쿠」에 모두 대응). `source` 기준으로 중복을 제거하는 도구는 그중 하나만 남깁니다. 구분이 필요하면 `terms.csv`의 `id`와 `src_table`로 문맥을 확인하십시오.
- **재생성**: 이 디렉터리는 `tools/split_by_language.py`가 `multilingual/`을 분할해 만든 것입니다. 스크립트는 고정된 외부 절대 경로(`E:\Download\BT\Codex_input\StellaSora_Glossary`)를 사용하며 **이 저장소를 읽거나 쓰지 않습니다**. 자세한 내용은 게임 루트의 `README.md` 「재생성」을 참고하십시오.
