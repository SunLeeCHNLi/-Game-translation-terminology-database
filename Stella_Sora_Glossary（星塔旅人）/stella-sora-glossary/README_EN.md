# Stella Sora (星塔旅人) Single-Language Terminology Database

## [简体中文](README.md) [日本語](README_JP.md)

This directory is the `stella-sora-glossary` data product of the *Stella Sora* (*星塔旅人* / ステラソラ) translation terminology database, split by **target language** into 5 independent directories: `zh-CN` (Simplified Chinese), `zh-TW` (Traditional Chinese), `en-US` (English), `ja-JP` (Japanese), `ko-KR` (Korean).

The 15 category CSVs in each language directory are all **laid out flat directly under the language directory**, and `NN_xxx/` subdirectories are no longer used. `<cat>.csv` is the glossary, in the format `source,target,tgt_lng`; `<cat>__terms.csv` is that language's entry list, in the format `id,term,src_table`. `_master/` stores each language's merged master table, index and existing notes; `multilingual/` keeps the original five-language side-by-side master table.

```text
├── zh-TW/

├── _master/
│   ├── zh-CN__all_glossary.csv
│   ├── zh-CN__all_terms.csv
│   ├── zh-CN__index.csv
│   └── ...
└── multilingual/             # original five-language side-by-side master table, internal layout unchanged
```

## File Format

The single-language category CSVs use the following fixed 3-column header:

| source | target | tgt_lng |
| --- | --- | --- |
| Amber | 琥珀 | zh-CN |
| コハク | 琥珀 | zh-CN |

`<cat>.csv` is encoded as **UTF-8 BOM** with **CRLF** line endings; `target` is the translation in the language specified by `tgt_lng`, and `source` is the original text in another language. `<cat>__terms.csv`, in turn, records that language's entry list as `id,term,src_table`.

## Regeneration

The data in this directory is regenerated by the scripts under `../tools/`:

```bash
python ../tools/build_glossary.py
python ../tools/split_by_language.py
```

`build_glossary.py` builds the five-language side-by-side master table from the upstream multilingual text library; `split_by_language.py` splits it by target language and generates the per-language category CSVs. For the specific external input paths and script behavior, see the game root's `README.md` / `README_EN.md` / `README_JP.md`.
